# Mapskill M2: inkrementell graf och daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gör analysmotorn från M1 levande. En bakgrundsprocess per projekt (daemon) håller grafen i minnet, ser filändringar, räknar om bara det som behövs och skickar ändringarna (`GraphDelta`) till anslutna klienter inom 2 sekunder. Hooks (M3) och kartvyn (M4) pratar med den över HTTP och WebSocket på `127.0.0.1` med en hemlig token.

**Architecture:** `@mapskill/core` får ett projekttillstånd (`Project`) med filfakta per fil. Vid en ändring parsas bara de ändrade filerna om; resten av grafen (länkar, noder, kanter, fynd) byggs om från alla filfakta, vilket mätt tar cirka 200 ms på 500 filer. Skillnaden mot förra grafen blir en `GraphDelta`. På så vis blir den inkrementella grafen identisk med en full skanning per konstruktion, och ett egenskapstest bevisar det. CLI-paketet får daemonen: filvakt (chokidar), ändringskö med debounce, HTTP- och WebSocket-server, varvsspårning för Stop-hooken, cache på disk, `daemon.json`, självavstängning och `ensureDaemon` som startar om en död daemon.

**Tech Stack:** Node 22, pnpm-arbetsyta, TypeScript `~5.9.3`, Vitest, tsx. Nya beroenden: `chokidar` `^4.0.3` (filvakt, ren JavaScript) och `ws` `^8.18.0` (WebSocket-server, ren JavaScript), `@types/ws` `^8.18.0`.

Spec: [../specs/2026-10-30-mapskill-mvp-design.md](../specs/2026-10-30-mapskill-mvp-design.md). Färdplan: [2026-10-30-mapskill-roadmap.md](2026-10-30-mapskill-roadmap.md). Föregående plan: [2026-10-30-m1-analysis-engine.md](2026-10-30-m1-analysis-engine.md).

## Global Constraints

- Node `>=22`. pnpm `>=10`.
- `typescript` låst till `~5.9.3` som körberoende i `@mapskill/core`. Använd inte TypeScript 7 (Go-porten har ett annat API).
- Inga native-beroenden i `@mapskill/core` eller `mapskill` (måste installeras på Windows utan byggverktyg). Enda nya beroenden: `chokidar` `^4.0.3` och `ws` `^8.18.0` i `mapskill`, `@types/ws` `^8.18.0` som dev-beroende.
- Alla sökvägar i datamodellen är relativa till projektroten och använder `/` även på Windows.
- All text som visas för användaren i kartan är `{ en: string; sv: string }`. CLI-meddelanden från `status`, `stop` och `daemon` är på engelska (beslut B6).
- Ingen nätverkstrafik utöver `127.0.0.1`, ingen LLM, ingen telemetri.
- `@mapskill/core` har inga sidoeffekter utöver filläsning: inga skrivningar, inga timers, inget nätverk. Allt sådant ligger i `packages/cli`.
- Daemonen lyssnar endast på `127.0.0.1` på en slumpad ledig port. Varje HTTP-anrop kräver headern `x-mapskill-token`. WebSocket-klienter måste skicka `{ "type": "hello", "token": "…" }` som första meddelande inom 2 sekunder, annars stängs anslutningen med kod `4401`. Host-headern måste vara `127.0.0.1:<port>` eller `localhost:<port>`, annars svar `403`.
- Mapskill skriver bara i `.mapskill/` och, en gång, lägger till rader i en befintlig `.gitignore`.
- Tidsgränser: debounce 200 ms med högst 1 000 ms total väntan, driftkontroll var 60:e sekund när ändringar skett, självavstängning efter 30 minuter utan ansluten klient och utan anrop, `ensureDaemon` väntar som standard högst 3 sekunder.
- Prestanda: från filändring till pushad delta under 2 sekunder på ett genererat projekt med 500 filer.
- Säkerhet för fynd och alla tröskelvärden från M1 är oförändrade. Säkra fynd får aldrig uppstå i `fixtures/clean-app`, `fixtures/conventions-app` eller `fixtures/beginner-app`.
- Modulsystem: ESM (`"type": "module"`), importer utan filändelse, `moduleResolution: "Bundler"`.

```ts
import fs from 'node:fs';
import path from 'node:path';
import ignore, { type Ignore } from 'ignore';

const SKIP_ANYWHERE = new Set(['node_modules', '.next', '.git', '.mapskill', '.vercel', '.turbo', 'coverage']);
const SKIP_AT_ROOT = new Set(['dist', 'build', 'out', 'public']);
const CODE_EXT = /\.(tsx?|jsx?|mjs|cjs)$/;

function loadIgnore(root: string): Ignore {
  const ig = ignore();
  const gitignore = path.join(root, '.gitignore');
  if (fs.existsSync(gitignore)) ig.add(fs.readFileSync(gitignore, 'utf8'));
  return ig;
}

function isCodeFileName(name: string): boolean {
  return CODE_EXT.test(name) && !name.endsWith('.d.ts');
}

/** True when a project-relative path lies in a folder Mapskill never reads (node_modules anywhere, dist/build/out/public at the root, ...). */
export function isSkippedDir(relDir: string): boolean {
  return relDir.split('/').some((part, i) => SKIP_ANYWHERE.has(part) || (i === 0 && SKIP_AT_ROOT.has(part)));
}

export function listSourceFiles(root: string): string[] {
  const ig = loadIgnore(root);
  const out: string[] = [];
  const walk = (dirRel: string): void => {
    for (const entry of fs.readdirSync(path.join(root, dirRel), { withFileTypes: true })) {
      const rel = dirRel ? `${dirRel}/${entry.name}` : entry.name;
      if (entry.isDirectory()) {
        if (SKIP_ANYWHERE.has(entry.name) || (!dirRel && SKIP_AT_ROOT.has(entry.name)) || ig.ignores(`${rel}/`)) continue;
        walk(rel);
      } else if (entry.isFile() && isCodeFileName(entry.name) && !ig.ignores(rel)) {
        out.push(rel);
      }
    }
  };
  walk('');
  return out.sort();
}

/** Same rules as listSourceFiles, for one project-relative path that may not exist (yet). */
export function createSourceFilter(root: string): (rel: string) => boolean {
  const ig = loadIgnore(root);
  return (rel) => {
    if (!rel || rel === '..' || rel.startsWith('../') || path.isAbsolute(rel)) return false;
    const parts = rel.split('/');
    if (!isCodeFileName(parts[parts.length - 1])) return false;
    for (let i = 0; i < parts.length - 1; i++) {
      const dir = parts.slice(0, i + 1).join('/');
      if (isSkippedDir(dir) || ig.ignores(`${dir}/`)) return false;
    }
    return !ig.ignores(rel);
  };
}
```

export function createResolver(root: string): Resolver {
  const { options, error } = loadCompilerOptions(root);
  const pathPrefixes = Object.keys(options.paths ?? {}).map((k) => k.replace(/\*$/, '')).filter((k) => k.length > 0);
  const newCache = (): ts.ModuleResolutionCache => ts.createModuleResolutionCache(root, (f) => f, options);
  let cache = newCache();
  return {
    configError: error,
    pathPrefixes,
    clearCache() {
      cache = newCache();
    },
    resolve(specifier, fromFile) {
      const containing = path.join(root, fromFile);
      const resolved = ts.resolveModuleName(specifier, containing, options, ts.sys, cache).resolvedModule;
      if (!resolved || resolved.isExternalLibraryImport) return null;
      const rel = path.relative(root, resolved.resolvedFileName).split(path.sep).join('/');
      if (rel.startsWith('..') || rel.includes('node_modules/') || rel.endsWith('.d.ts')) return null;
      return rel;
    },
  };
}

- [ ] **Step 6: Skapa `graph/project.ts`**

Koden för länkar, modell och analyser flyttas oförändrad från `scanProject` i M1. Det nya är att filerna sorteras, att läsningen ligger i `readSourceFile` och att överhoppade filer ligger i `project.skipped`.

```ts
import fs from 'node:fs';
import path from 'node:path';
import { buildModel } from '../adapters/build-model';
import { isNextProject, readPrismaModels } from '../adapters/nextjs/project';
import { computeHealth } from '../analyze/health';
import { runAnalyzers } from '../analyze/index';
import type { FileFacts, FileLink, Framework, Graph } from '../model/types';
import { extractFacts } from '../parse/extract';
import { createResolver, type Resolver } from '../resolve/resolver';
import { listSourceFiles } from '../scan/files';
import { sha1 } from '../util/hash';

export const MAX_FILE_BYTES = 1_000_000;
const ASSET_SPECIFIER = /\.(css|scss|sass|less|svg|png|jpe?g|gif|webp|avif|ico|json|md|mdx|txt|woff2?|ttf|otf|mp4|webm|pdf)$/i;

/** Everything Mapskill knows about one project. `facts` and `skipped` change as files change; the rest is read once per load. */
export interface Project {
  root: string;
  framework: Framework;
  resolver: Resolver;
  prismaModels: string[];
  shadcn: boolean;
  /** Facts per project-relative source file. */
  facts: Record<string, FileFacts>;
  /** Source files that exist but were not read (too large or unreadable). */
  skipped: Set<string>;
  graph: Graph;
}

export type ReadResult = FileFacts | 'missing' | 'skipped';

/** Reads one source file. Reuses `previous` when the content hash is unchanged (only the mtime is refreshed). */
export function readSourceFile(root: string, rel: string, previous?: FileFacts): ReadResult {
  const abs = path.join(root, rel);
  let stat: fs.Stats;
  try {
    stat = fs.statSync(abs);
  } catch (err) {
    const code = (err as NodeJS.ErrnoException).code;
    return code === 'ENOENT' || code === 'ENOTDIR' ? 'missing' : 'skipped';
  }
  if (!stat.isFile()) return 'missing';
  if (stat.size > MAX_FILE_BYTES) return 'skipped';
  let text: string;
  try {
    text = fs.readFileSync(abs, 'utf8');
  } catch {
    return 'skipped';
  }
  if (previous && previous.hash === sha1(text)) return { ...previous, mtimeMs: stat.mtimeMs };
  return extractFacts(rel, text, stat.mtimeMs);
}

/** Records a read result. Returns true when a file appeared on disk or disappeared from it. */
export function storeRead(project: Project, rel: string, result: ReadResult): boolean {
  const known = rel in project.facts || project.skipped.has(rel);
  delete project.facts[rel];
  project.skipped.delete(rel);
  if (result === 'missing') return known;
  if (result === 'skipped') project.skipped.add(rel);
  else project.facts[rel] = result;
  return !known;
}

export function loadProject(root: string, cached: Record<string, FileFacts> = {}): Project {
  const project: Project = {
    root,
    framework: isNextProject(root) ? 'nextjs' : 'generic',
    resolver: createResolver(root),
    prismaModels: readPrismaModels(root),
    shadcn: fs.existsSync(path.join(root, 'components.json')),
    facts: {},
    skipped: new Set(),
    graph: undefined as unknown as Graph,
  };
  for (const rel of listSourceFiles(root)) storeRead(project, rel, readSourceFile(root, rel, cached[rel]));
  project.graph = buildGraph(project);
  return project;
}

function nestedPackageDirsOf(root: string, paths: string[]): string[] {
  const checked = new Map<string, boolean>();
  const hasPackage = (dir: string): boolean => {
    if (!checked.has(dir)) checked.set(dir, fs.existsSync(path.join(root, dir, 'package.json')));
    return checked.get(dir)!;
  };
  const out = new Set<string>();
  for (const p of paths) {
    const parts = p.split('/').slice(0, -1);
    for (let i = 1; i <= parts.length; i++) {
      const dir = parts.slice(0, i).join('/');
      if (hasPackage(dir)) out.add(dir);
    }
  }
  return [...out].sort();
}

/** Derives links, nodes, edges, findings and health from the current facts. Files are processed in sorted order, so the result does not depend on insertion order. */
export function buildGraph(project: Project): Graph {
  const { root, framework, resolver } = project;
  const files: Record<string, FileFacts> = {};
  for (const rel of Object.keys(project.facts).sort()) files[rel] = project.facts[rel];

  const cache = new Map<string, string | null>();
  const resolve = (specifier: string, from: string): string | null => {
    const key = `${from}\u0000${specifier}`;
    if (!cache.has(key)) cache.set(key, resolver.resolve(specifier, from));
    return cache.get(key) ?? null;
  };

  const isLocalSpecifier = (spec: string): boolean =>
    /^(\.{1,2}\/|@\/|~\/)/.test(spec) || resolver.pathPrefixes.some((p) => spec.startsWith(p));
  let unresolvedLocal = false;
  const links: FileLink[] = [];
  for (const f of Object.values(files)) {
    for (const imp of f.imports) {
      const to = resolve(imp.specifier, f.path);
      if (!to && isLocalSpecifier(imp.specifier) && !ASSET_SPECIFIER.test(imp.specifier)) unresolvedLocal = true;
      if (to && files[to]) links.push({ from: f.path, to, names: imp.bindings.map((b) => b.imported), typeOnly: imp.typeOnly });
    }
  }

  const model = buildModel({ files, resolve, prismaModels: project.prismaModels, framework });
  const hasAppDir = ['app', 'src/app', 'pages', 'src/pages'].some((d) => fs.existsSync(path.join(root, d)));
  const degraded =
    project.skipped.size > 0 || unresolvedLocal || Boolean(resolver.configError) || (framework === 'generic' && hasAppDir);
  const findings = runAnalyzers({
    files,
    links,
    nodes: model.nodes,
    owner: model.owner,
    framework,
    nestedPackageDirs: nestedPackageDirsOf(root, Object.keys(files)),
    degraded,
    shadcn: project.shadcn,
  });
  return {
    root,
    framework,
    files,
    links,
    nodes: model.nodes,
    edges: model.edges,
    findings,
    health: computeHealth(model.nodes, findings),
  };
}
```

```ts
import type { Finding, Framework, Graph, MapEdge, MapNode } from '../model/types';

/** The graph as clients see it: no per-file facts or file links. */
export interface PublicGraph {
  root: string;
  framework: Framework;
  nodes: MapNode[];
  edges: MapEdge[];
  findings: Finding[];
  health: Record<string, number>;
  fileCount: number;
  /** Files whose latest content could not be parsed, sorted. */
  unreadableFiles: string[];
}

export interface GraphDelta {
  addedNodes: MapNode[];
  removedNodeIds: string[];
  changedNodes: MapNode[];
  addedEdges: MapEdge[];
  removedEdgeIds: string[];
  addedFindings: Finding[];
  resolvedFindingIds: string[];
  changedFindings: Finding[];
  framework: Framework;
  health: Record<string, number>;
  fileCount: number;
  unreadableFiles: string[];
}

export function toPublicGraph(g: Graph): PublicGraph {
  return {
    root: g.root,
    framework: g.framework,
    nodes: g.nodes,
    edges: g.edges,
    findings: g.findings,
    health: g.health,
    fileCount: Object.keys(g.files).length,
    unreadableFiles: Object.values(g.files)
      .filter((f) => f.parseError)
      .map((f) => f.path)
      .sort(),
  };
}

interface Diff<T> {
  added: T[];
  removed: string[];
  changed: T[];
}

function diffById<T extends { id: string }>(before: T[], after: T[]): Diff<T> {
  const old = new Map(before.map((x) => [x.id, x]));
  const seen = new Set<string>();
  const added: T[] = [];
  const changed: T[] = [];
  for (const x of after) {
    seen.add(x.id);
    const prev = old.get(x.id);
    if (!prev) added.push(x);
    else if (JSON.stringify(prev) !== JSON.stringify(x)) changed.push(x);
  }
  return { added, removed: before.filter((x) => !seen.has(x.id)).map((x) => x.id), changed };
}

export function diffGraphs(before: PublicGraph, after: PublicGraph): GraphDelta {
  const n = diffById(before.nodes, after.nodes);
  const e = diffById(before.edges, after.edges);
  const f = diffById(before.findings, after.findings);
  return {
    addedNodes: n.added,
    removedNodeIds: n.removed,
    changedNodes: n.changed,
    addedEdges: [...e.added, ...e.changed],
    removedEdgeIds: [...e.removed, ...e.changed.map((x) => x.id)],
    addedFindings: f.added,
    resolvedFindingIds: f.removed,
    changedFindings: f.changed,
    framework: after.framework,
    health: after.health,
    fileCount: after.fileCount,
    unreadableFiles: after.unreadableFiles,
  };
}

export function isEmptyDelta(d: GraphDelta, before: PublicGraph): boolean {
  const lists = [
    d.addedNodes, d.removedNodeIds, d.changedNodes, d.addedEdges, d.removedEdgeIds,
    d.addedFindings, d.resolvedFindingIds, d.changedFindings,
  ];
  return (
    lists.every((l) => l.length === 0) &&
    d.framework === before.framework &&
    d.fileCount === before.fileCount &&
    d.unreadableFiles.join('\n') === before.unreadableFiles.join('\n') &&
    JSON.stringify(d.health) === JSON.stringify(before.health)
  );
}

function patch<T extends { id: string }>(list: T[], removed: string[], changed: T[], added: T[]): T[] {
  const gone = new Set(removed);
  const replacement = new Map(changed.map((x) => [x.id, x]));
  return [...list.filter((x) => !gone.has(x.id)).map((x) => replacement.get(x.id) ?? x), ...added];
}

/** Applies a delta to a graph. Kept items stay in place, added items are appended. */
export function applyDelta(g: PublicGraph, d: GraphDelta): PublicGraph {
  return {
    ...g,
    framework: d.framework,
    health: d.health,
    fileCount: d.fileCount,
    unreadableFiles: d.unreadableFiles,
    nodes: patch(g.nodes, d.removedNodeIds, d.changedNodes, d.addedNodes),
    edges: patch(g.edges, d.removedEdgeIds, [], d.addedEdges),
    findings: patch(g.findings, d.resolvedFindingIds, d.changedFindings, d.addedFindings),
  };
}
```

```ts
export interface ChangeResult {
  /** Always continue with this project: it is a new object when the project was reloaded. */
  project: Project;
  delta: GraphDelta;
  /** True when a project config file changed and everything was read again. */
  reloaded: boolean;
  /** True when nothing a client can see changed. */
  empty: boolean;
}

const PROJECT_CONFIG = new Set([
  'package.json', 'tsconfig.json', 'jsconfig.json', 'prisma/schema.prisma', 'components.json', '.gitignore',
]);

/** Files whose change affects how the whole project is read (framework, aliases, Prisma models, ignore rules, nested packages). */
export function isProjectConfigFile(rel: string): boolean {
  return PROJECT_CONFIG.has(rel) || rel.endsWith('/package.json') || /^tsconfig\.[^/]+\.json$/.test(rel);
}

function normalizeRel(p: string): string {
  return p.split('\\').join('/').replace(/^\.\//, '');
}

/** Re-reads the given project-relative paths and rebuilds the graph. Paths may be new, changed, deleted or not source files at all. */
export function applyFileChanges(project: Project, paths: string[]): ChangeResult {
  const rels = [...new Set(paths.map(normalizeRel))].filter((r) => r !== '');
  const before = toPublicGraph(project.graph);
  const finish = (next: Project, reloaded: boolean): ChangeResult => {
    const delta = diffGraphs(before, toPublicGraph(next.graph));
    return { project: next, delta, reloaded, empty: isEmptyDelta(delta, before) };
  };

  if (rels.some(isProjectConfigFile)) return finish(loadProject(project.root, project.facts), true);

  const isSource = createSourceFilter(project.root);
  const relevant = rels.filter((r) => isSource(r) || r in project.facts || project.skipped.has(r));
  if (relevant.length === 0) return finish(project, false);

  let fileSetChanged = false;
  for (const rel of relevant) {
    const result = isSource(rel) ? readSourceFile(project.root, rel, project.facts[rel]) : 'missing';
    if (storeRead(project, rel, result)) fileSetChanged = true;
  }
  if (fileSetChanged) project.resolver.clearCache();
  project.graph = buildGraph(project);
  return finish(project, false);
}

/** Source files that appeared, disappeared or got a different mtime since they were last read. Used as a safety net for missed watcher events. */
export function findDrift(project: Project): string[] {
  const listed = listSourceFiles(project.root);
  const listedSet = new Set(listed);
  const known = new Set([...Object.keys(project.facts), ...project.skipped]);
  const out = new Set<string>();
  for (const rel of listed) {
    if (!known.has(rel)) {
      out.add(rel);
      continue;
    }
    const facts = project.facts[rel];
    if (!facts) continue;
    try {
      if (fs.statSync(path.join(project.root, rel)).mtimeMs !== facts.mtimeMs) out.add(rel);
    } catch {
      out.add(rel);
    }
  }
  for (const rel of known) if (!listedSet.has(rel)) out.add(rel);
  return [...out].sort();
}

const OPS = ['+', '-', '*', '%'];

function generatedBody(seed: number, statements: number): string {
  const lines: string[] = [];
  for (let k = 0; k < statements; k++) {
    const v = `v${k}`;
    const prev = k > 0 ? `v${k - 1}` : 'x';
    switch ((seed * 7 + k * 3) % 5) {
      case 0:
        lines.push(`  const ${v} = ${prev} ${OPS[(seed + k) % 4]} ${seed + k};`);
        break;
      case 1:
        lines.push(`  const ${v} = [${prev}, ${k}].map((q) => q ${OPS[k % 4]} 1).length;`);
        break;
      case 2:
        lines.push(`  const ${v} = ${prev} > ${k} ? String(${prev}).length : ${k};`);
        break;
      case 3:
        lines.push(`  let ${v} = 0;`, `  for (let j = 0; j < ${k}; j++) { ${v} += j; }`);
        break;
      default:
        lines.push(`  const ${v} = Math.max(${prev}, ${seed % 11});`);
    }
  }
  return `${lines.join('\n')}\n  return v${statements - 1};`;
}

/** Writes a Next.js project with `fileCount` source files (1/5 pages, the rest split between components and helpers) and returns its root. */
export function generateProject(fileCount: number): string {
  const pages = Math.max(1, Math.floor(fileCount / 5));
  const components = Math.max(1, Math.floor((fileCount - pages) / 2));
  const helpers = Math.max(1, fileCount - pages - components);
  const files: Record<string, string> = {
    'package.json': JSON.stringify({ dependencies: { next: '15.0.0', react: '19.0.0' } }),
    'tsconfig.json': JSON.stringify({ compilerOptions: { jsx: 'preserve', baseUrl: '.', paths: { '@/*': ['./*'] } } }),
  };
  for (let i = 0; i < pages; i++) {
    const a = (2 * i) % components;
    const b = (2 * i + 1) % components;
    files[`app/p${i}/page.tsx`] =
      `import { C${a} } from '@/components/C${a}';\n` +
      (a === b ? '' : `import { C${b} } from '@/components/C${b}';\n`) +
      `export default function Page() {\n  return <main><C${a} n={${i}} />${a === b ? '' : `<C${b} n={${i}} />`}</main>;\n}\n`;
  }
  for (let i = 0; i < components; i++) {
    const h = i % helpers;
    files[`components/C${i}.tsx`] =
      `import { h${h} } from '@/lib/h${h}';\n` +
      `function calc(x: number) {\n${generatedBody(i, 6 + (i % 9))}\n}\n` +
      `export function C${i}(props: { n: number }) {\n  return <div>{h${h}(calc(props.n))}</div>;\n}\n`;
  }
  for (let i = 0; i < helpers; i++) {
    files[`lib/h${i}.ts`] = `export function h${i}(x: number): number {\n${generatedBody(i + 1000, 8 + (i % 13))}\n}\n`;
  }
  return tmpProject(files);
}

import fs from 'node:fs';
import path from 'node:path';

export const MAPSKILL_DIR = '.mapskill';

export function mapskillPath(root: string, name: string): string {
  return path.join(root, MAPSKILL_DIR, name);
}

export function ensureMapskillDir(root: string): void {
  fs.mkdirSync(path.join(root, MAPSKILL_DIR), { recursive: true });
}

/** Adds .mapskill/ to an existing .gitignore, once. Returns true when the file was changed. Never creates a .gitignore. */
export function ensureGitignore(root: string): boolean {
  const file = path.join(root, '.gitignore');
  if (!fs.existsSync(file)) return false;
  const text = fs.readFileSync(file, 'utf8');
  if (/^\/?\.mapskill(\/\*?)?\s*$/m.test(text)) return false;
  const separator = text.length === 0 || text.endsWith('\n') ? '' : '\n';
  fs.appendFileSync(file, `${separator}\n# Mapskill (local map data)\n.mapskill/*\n!.mapskill/goal.yaml\n`);
  return true;
}

function sleepSync(ms: number): void {
  Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms);
}

/** Writes JSON to a temporary file and renames it over the target, so readers never see half a file. Retries briefly when Windows holds the target open. */
export function writeJsonAtomic(file: string, data: unknown): void {
  const tmp = `${file}.${process.pid}.${Date.now()}.tmp`;
  fs.writeFileSync(tmp, JSON.stringify(data));
  for (let attempt = 0; ; attempt++) {
    try {
      fs.renameSync(tmp, file);
      return;
    } catch (err) {
      if (attempt >= 4) {
        fs.rmSync(tmp, { force: true });
        throw err;
      }
      sleepSync(20);
    }
  }
}

export function readJson<T>(file: string): T | null {
  try {
    return JSON.parse(fs.readFileSync(file, 'utf8')) as T;
  } catch {
    return null;
  }
}

/** Contents of .mapskill/daemon.json: how other processes find the running daemon. */
export interface DaemonInfo {
  pid: number;
  port: number;
  token: string;
  version: string;
  root: string;
  startedAt: number;
}

const INFO_FILE = 'daemon.json';
const LOCK_FILE = 'daemon.lock';

export function readDaemonInfo(root: string): DaemonInfo | null {
  const info = readJson<Partial<DaemonInfo>>(mapskillPath(root, INFO_FILE));
  if (!info || typeof info.pid !== 'number' || typeof info.port !== 'number' || typeof info.token !== 'string') return null;
  return info as DaemonInfo;
}

export function writeDaemonInfo(root: string, info: DaemonInfo): void {
  ensureMapskillDir(root);
  writeJsonAtomic(mapskillPath(root, INFO_FILE), info);
}

/** Removes daemon.json only when it still belongs to `pid` (a newer daemon may have replaced it). */
export function removeDaemonInfo(root: string, pid: number): void {
  if (readDaemonInfo(root)?.pid === pid) fs.rmSync(mapskillPath(root, INFO_FILE), { force: true });
}

export function isPidAlive(pid: number): boolean {
  if (!Number.isInteger(pid) || pid <= 0) return false;
  try {
    process.kill(pid, 0);
    return true;
  } catch (err) {
    return (err as NodeJS.ErrnoException).code === 'EPERM';
  }
}

/** Claims the start lock. False when another live process took it less than `staleMs` ago. */
export function acquireStartLock(root: string, staleMs = 10_000): boolean {
  ensureMapskillDir(root);
  const file = mapskillPath(root, LOCK_FILE);
  try {
    fs.writeFileSync(file, String(process.pid), { flag: 'wx' });
    return true;
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code !== 'EEXIST') return false;
  }
  try {
    const holder = Number(fs.readFileSync(file, 'utf8').trim());
    const age = Date.now() - fs.statSync(file).mtimeMs;
    if (holder !== process.pid && isPidAlive(holder) && age < staleMs) return false;
  } catch {
    // unreadable lock: take it over
  }
  fs.writeFileSync(file, String(process.pid));
  return true;
}

export function releaseStartLock(root: string): void {
  const file = mapskillPath(root, LOCK_FILE);
  try {
    if (Number(fs.readFileSync(file, 'utf8').trim()) === process.pid) fs.rmSync(file, { force: true });
  } catch {
    // already gone
  }
}

export type Actor = 'claude' | 'watcher';

export interface ChangeBatch {
  /** All changed project-relative paths, sorted. */
  paths: string[];
  /** The subset Claude reported through a hook, sorted. */
  byClaude: string[];
}

/** Collects changed paths and hands them over in one batch after a quiet period (debounce), at the latest `maxWaitMs` after the first one. */
export class ChangeQueue {
  private readonly pending = new Map<string, Actor>();
  private timer: ReturnType<typeof setTimeout> | undefined;
  private firstAt = 0;

  constructor(
    private readonly onFlush: (batch: ChangeBatch) => void,
    private readonly delayMs = 200,
    private readonly maxWaitMs = 1000,
  ) {}

  get size(): number {
    return this.pending.size;
  }

  add(rel: string, by: Actor): void {
    if (this.pending.size === 0) this.firstAt = Date.now();
    if (this.pending.get(rel) !== 'claude') this.pending.set(rel, by);
    if (this.timer) clearTimeout(this.timer);
    const wait = Math.max(0, Math.min(this.delayMs, this.firstAt + this.maxWaitMs - Date.now()));
    this.timer = setTimeout(() => this.flushNow(), wait);
  }

  flushNow(): void {
    if (this.timer) clearTimeout(this.timer);
    this.timer = undefined;
    if (this.pending.size === 0) return;
    const entries = [...this.pending].sort(([a], [b]) => a.localeCompare(b));
    this.pending.clear();
    this.onFlush({
      paths: entries.map(([p]) => p),
      byClaude: entries.filter(([, by]) => by === 'claude').map(([p]) => p),
    });
  }

  dispose(): void {
    if (this.timer) clearTimeout(this.timer);
    this.timer = undefined;
    this.pending.clear();
  }
}

import { randomUUID } from 'node:crypto';
import type { Certainty, Finding } from '@mapskill/core';

interface Turn {
  sessionId: string;
  /** Finding ids that existed when the turn started. */
  baseline: Set<string>;
  /** Files Claude reported touching during the turn. */
  touched: Set<string>;
}

export interface FindingQuery {
  touchedOnly?: boolean;
  certainty?: Certainty;
}

const MAX_TURNS = 100;

/** Remembers, per Claude session, which findings existed when a turn began and which files Claude touched since. */
export class TurnTracker {
  private readonly turns = new Map<string, Turn>();
  private readonly current = new Map<string, string>();

  startTurn(sessionId: string, currentFindingIds: Iterable<string>): string {
    const id = randomUUID();
    this.turns.set(id, { sessionId, baseline: new Set(currentFindingIds), touched: new Set() });
    this.current.set(sessionId, id);
    while (this.turns.size > MAX_TURNS) {
      const oldest = this.turns.keys().next().value as string;
      this.turns.delete(oldest);
    }
    return id;
  }

  currentTurn(sessionId: string): string | undefined {
    const id = this.current.get(sessionId);
    return id !== undefined && this.turns.has(id) ? id : undefined;
  }

  /** Records touched files in the session's current turn, starting one if needed. Returns the turn id. */
  touch(sessionId: string, files: string[], currentFindingIds: Iterable<string>): string {
    const id = this.currentTurn(sessionId) ?? this.startTurn(sessionId, currentFindingIds);
    const turn = this.turns.get(id)!;
    for (const file of files) turn.touched.add(file);
    return id;
  }

  newFindings(turnId: string, findings: Finding[], query: FindingQuery = {}): Finding[] {
    const turn = this.turns.get(turnId);
    if (!turn) return [];
    return findings.filter(
      (f) =>
        !turn.baseline.has(f.id) &&
        (!query.certainty || f.certainty === query.certainty) &&
        (!query.touchedOnly || f.files.some((file) => turn.touched.has(file))),
    );
  }
}

import path from 'node:path';
import { isSkippedDir } from '@mapskill/core';
import { watch } from 'chokidar';

export interface WatchEvent {
  /** Project-relative path with '/' separators. */
  rel: string;
  kind: 'file' | 'dir-removed';
}

export interface ProjectWatcher {
  close(): Promise<void>;
}

/** Watches the project for added, changed and removed files. Resolves once the initial crawl is done. */
export async function watchProject(
  root: string,
  onEvent: (e: WatchEvent) => void,
  onError: (err: unknown) => void = () => {},
): Promise<ProjectWatcher> {
  const toRel = (abs: string): string => path.relative(root, abs).split(path.sep).join('/');
  const watcher = watch(root, {
    ignoreInitial: true,
    ignored: (abs: string) => {
      const rel = toRel(abs);
      return rel !== '' && !rel.startsWith('..') && isSkippedDir(rel);
    },
  });
  const onFile = (abs: string): void => onEvent({ rel: toRel(abs), kind: 'file' });
  watcher.on('add', onFile);
  watcher.on('change', onFile);
  watcher.on('unlink', onFile);
  watcher.on('unlinkDir', (abs: string) => onEvent({ rel: toRel(abs), kind: 'dir-removed' }));
  watcher.on('error', onError);
  await new Promise<void>((resolve) => watcher.once('ready', () => resolve()));
  return { close: () => watcher.close() };
}
```

export class DaemonRequestError extends Error {
  constructor(
    readonly status: number,
    message: string,
  ) {
    super(message);
  }

/** Calls the daemon's HTTP API with the token. Throws DaemonRequestError for non-2xx answers. */
export async function request<T>(
  info: { port: number; token: string },
  method: 'GET' | 'POST',
  pathname: string,
  body?: unknown,
  timeoutMs = 2000,
): Promise<T> {
  const res = await fetch(`http://127.0.0.1:${info.port}${pathname}`, {
    method,
    headers: { 'x-mapskill-token': info.token, ...(body === undefined ? {} : { 'content-type': 'application/json' }) },
    body: body === undefined ? undefined : JSON.stringify(body),
    signal: AbortSignal.timeout(timeoutMs),
  });
  const json = (await res.json()) as T & { error?: string };
  if (!res.ok) throw new DaemonRequestError(res.status, json.error ?? res.statusText);
  return json;
}

```ts
import { timingSafeEqual } from 'node:crypto';
import http from 'node:http';
import type { AddressInfo } from 'node:net';
import type { Certainty, ClientMessage, DaemonStatus, Finding, PublicGraph, ServerMessage } from '@mapskill/core';
import { WebSocket, WebSocketServer } from 'ws';

export interface ServerDeps {
  token: string;
  status(): DaemonStatus;
  graph(): Promise<PublicGraph>;
  /** First message for a client that said hello: the full graph. */
  hello(): Promise<ServerMessage>;
  touched(input: { files: string[]; toolUseId?: string; sessionId?: string }): Promise<void>;
  startTurn(sessionId: string): Promise<string>;
  findings(turnId: string, query: { touchedOnly: boolean; certainty?: Certainty }): Promise<Finding[]>;
  shutdown(): void;
  /** Called for every authenticated request or message (keeps the daemon from idling out). */
  activity(): void;
}

export interface DaemonServer {
  port: number;
  broadcast(m: ServerMessage): void;
  clientCount(): number;
  close(): Promise<void>;
}

const MAX_BODY_BYTES = 1_000_000;

class HttpError extends Error {
  constructor(
    readonly status: number,
    message: string,
  ) {
    super(message);
  }
}

function sameToken(given: unknown, expected: string): boolean {
  if (typeof given !== 'string') return false;
  const a = Buffer.from(given);
  const b = Buffer.from(expected);
  return a.length === b.length && timingSafeEqual(a, b);
}

function optionalString(v: unknown): string | undefined {
  return typeof v === 'string' ? v : undefined;
}

async function readBody(req: http.IncomingMessage): Promise<Record<string, unknown>> {
  const chunks: Buffer[] = [];
  let size = 0;
  for await (const chunk of req) {
    size += (chunk as Buffer).length;
    if (size > MAX_BODY_BYTES) throw new HttpError(413, 'body too large');
    chunks.push(chunk as Buffer);
  }
  if (size === 0) return {};
  let parsed: unknown;
  try {
    parsed = JSON.parse(Buffer.concat(chunks).toString('utf8'));
  } catch {
    throw new HttpError(400, 'invalid JSON');
  }
  if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) throw new HttpError(400, 'body must be a JSON object');
  return parsed as Record<string, unknown>;
}

function send(res: http.ServerResponse, status: number, body: unknown): void {
  res.writeHead(status, { 'content-type': 'application/json; charset=utf-8', 'cache-control': 'no-store' });
  res.end(JSON.stringify(body));
}

export async function startServer(deps: ServerDeps, options: { helloTimeoutMs?: number } = {}): Promise<DaemonServer> {
  let port = 0;
  const clients = new Set<WebSocket>();
  const allowedHost = (host: string | undefined): boolean => host === `127.0.0.1:${port}` || host === `localhost:${port}`;

  async function handle(req: http.IncomingMessage, res: http.ServerResponse): Promise<void> {
    if (!allowedHost(req.headers.host)) throw new HttpError(403, 'forbidden host');
    if (!sameToken(req.headers['x-mapskill-token'], deps.token)) throw new HttpError(401, 'missing or wrong token');
    deps.activity();
    const url = new URL(req.url ?? '/', `http://127.0.0.1:${port}`);
    switch (`${req.method} ${url.pathname}`) {
      case 'GET /api/status':
        return send(res, 200, deps.status());
      case 'GET /api/graph':
        return send(res, 200, await deps.graph());
      case 'POST /api/touched': {
        const body = await readBody(req);
        const files = body.files;
        if (!Array.isArray(files) || !files.every((f) => typeof f === 'string')) throw new HttpError(400, 'files must be a list of strings');
        await deps.touched({ files: files as string[], toolUseId: optionalString(body.toolUseId), sessionId: optionalString(body.sessionId) });
        return send(res, 200, { ok: true });
      }
      case 'POST /api/turn': {
        const body = await readBody(req);
        return send(res, 200, { turnId: await deps.startTurn(optionalString(body.sessionId) ?? 'default') });
      }
      case 'GET /api/findings': {
        const since = url.searchParams.get('since');
        if (!since) throw new HttpError(400, 'since is required');
        const certainty = url.searchParams.get('certainty');
        if (certainty !== null && certainty !== 'certain' && certainty !== 'likely') throw new HttpError(400, 'certainty must be certain or likely');
        const findings = await deps.findings(since, {
          touchedOnly: url.searchParams.get('touchedOnly') === 'true',
          ...(certainty ? { certainty } : {}),
        });
        return send(res, 200, { findings });
      }
      case 'POST /api/shutdown':
        send(res, 200, { ok: true });
        setImmediate(() => deps.shutdown());
        return;
      default:
        throw new HttpError(404, 'not found');
    }
  }

  const server = http.createServer((req, res) => {
    handle(req, res).catch((err: unknown) => {
      if (res.headersSent) return;
      if (err instanceof HttpError) send(res, err.status, { error: err.message });
      else send(res, 500, { error: 'internal error' });
    });
  });

  const wss = new WebSocketServer({ noServer: true, maxPayload: 64 * 1024 });
  server.on('upgrade', (req, socket, head) => {
    const pathname = new URL(req.url ?? '/', 'http://127.0.0.1').pathname;
    if (pathname !== '/ws' || !allowedHost(req.headers.host)) {
      socket.write('HTTP/1.1 403 Forbidden\r\n\r\n');
      socket.destroy();
      return;
    }
    wss.handleUpgrade(req, socket, head, (ws) => {
      const timer = setTimeout(() => ws.close(4401, 'hello required'), options.helloTimeoutMs ?? 2000);
      ws.once('message', (data) => {
        clearTimeout(timer);
        let msg: Partial<ClientMessage> | undefined;
        try {
          msg = JSON.parse(String(data)) as Partial<ClientMessage>;
        } catch {
          msg = undefined;
        }
        if (msg?.type !== 'hello' || !sameToken(msg.token, deps.token)) {
          ws.close(4401, 'wrong token');
          return;
        }
        deps.activity();
        ws.on('message', () => deps.activity());
        deps.hello().then(
          (first) => {
            if (ws.readyState !== WebSocket.OPEN) return;
            ws.send(JSON.stringify(first));
            clients.add(ws);
          },
          () => ws.close(1011, 'graph unavailable'),
        );
      });
      ws.on('close', () => {
        clearTimeout(timer);
        clients.delete(ws);
      });
      ws.on('error', () => clients.delete(ws));
    });
  });

  await new Promise<void>((resolve, reject) => {
    server.once('error', reject);
    server.listen(0, '127.0.0.1', () => resolve());
  });
  port = (server.address() as AddressInfo).port;

  return {
    port,
    broadcast(m) {
      const text = JSON.stringify(m);
      for (const ws of clients) if (ws.readyState === WebSocket.OPEN) ws.send(text);
    },
    clientCount: () => clients.size,
    async close() {
      for (const ws of wss.clients) ws.terminate();
      wss.close();
      server.closeAllConnections();
      await new Promise<void>((resolve) => server.close(() => resolve()));
    },
  };
}

import { randomBytes } from 'node:crypto';
import path from 'node:path';
import {
  applyFileChanges,
  findDrift,
  loadProject,
  toPublicGraph,
  type DaemonStatus,
  type Project,
  type PublicGraph,
} from '@mapskill/core';
import { readFactsCache, writeFactsCache } from './cache';
import { DAEMON_VERSION, readDaemonInfo, removeDaemonInfo, writeDaemonInfo, type DaemonInfo } from './info';
import { ensureGitignore, ensureMapskillDir } from './paths';
import { ChangeQueue, type ChangeBatch } from './queue';
import { startServer } from './server';
import { TurnTracker } from './turns';
import { watchProject, type ProjectWatcher } from './watcher';

export interface DaemonOptions {
  /** Stop after this long without connected clients or requests. Default 30 minutes. */
  idleMs?: number;
  /** Quiet period before a batch of changes is applied. Default 200 ms. */
  debounceMs?: number;
  /** How often to look for changes the watcher missed (only after changes happened). Default 60 seconds. */
  reconcileMs?: number;
  /** Delay before the facts cache is written after changes. Default 5 seconds. */
  cacheSaveMs?: number;
  /** False runs without a file watcher (changes then only arrive through /api/touched). Default true. */
  watch?: boolean;
  log?: (line: string) => void;
}

export interface DaemonHandle {
  info: DaemonInfo;
  /** Resolves when the project is loaded and the watcher (if any) is running. */
  ready: Promise<void>;
  /** Resolves with the reason once the daemon has stopped. */
  done: Promise<string>;
  stop(reason?: string): Promise<void>;
  project(): Project | undefined;
}

/** Project-relative path with '/' separators, or null when `file` lies outside the project (or is the root itself). */
export function toProjectRel(root: string, file: string): string | null {
  const rel = path.relative(root, path.resolve(root, file)).split(path.sep).join('/');
  if (rel === '' || rel === '..' || rel.startsWith('../') || path.isAbsolute(rel)) return null;
  return rel;
}

export async function startDaemon(rootArg: string, options: DaemonOptions = {}): Promise<DaemonHandle> {
  const root = path.resolve(rootArg);
  const log = options.log ?? (() => {});
  const idleMs = options.idleMs ?? 30 * 60_000;
  ensureMapskillDir(root);
  if (ensureGitignore(root)) log('added .mapskill/ to .gitignore');

  const token = randomBytes(24).toString('hex');
  const turns = new TurnTracker();
  const timers: ReturnType<typeof setInterval>[] = [];
  let project: Project | undefined;
  let seq = 0;
  let lastActivity = Date.now();
  let changedSinceReconcile = false;
  let watcher: ProjectWatcher | undefined;
  let cacheTimer: ReturnType<typeof setTimeout> | undefined;
  let stopping: Promise<void> | undefined;
  let resolveDone!: (reason: string) => void;
  const done = new Promise<string>((resolve) => {
    resolveDone = resolve;
  });

  const saveCache = (): void => {
    if (!project) return;
    try {
      writeFactsCache(root, project.facts);
    } catch (err) {
      log(`cache write failed: ${String(err)}`);
    }
  };
  const scheduleCacheSave = (): void => {
    if (cacheTimer) return;
    cacheTimer = setTimeout(() => {
      cacheTimer = undefined;
      saveCache();
    }, options.cacheSaveMs ?? 5000);
  };

  const onFlush = (batch: ChangeBatch): void => {
    if (!project) return;
    const known = new Set([...Object.keys(project.facts), ...project.skipped]);
    try {
      const result = applyFileChanges(project, batch.paths);
      const current = result.project;
      project = current;
      changedSinceReconcile = true;
      if (!result.empty) {
        seq += 1;
        server.broadcast({ type: 'delta', seq, delta: result.delta });
        scheduleCacheSave();
      }
      const relevant = batch.paths.filter((p) => known.has(p) || p in current.facts || current.skipped.has(p));
      if (relevant.length > 0) {
        const claude = new Set(batch.byClaude);
        server.broadcast({
          type: 'activity',
          at: Date.now(),
          files: relevant.map((p) => ({ path: p, by: claude.has(p) ? 'claude' : 'watcher' })),
        });
      }
    } catch (err) {
      log(`update failed: ${err instanceof Error ? (err.stack ?? err.message) : String(err)}`);
    }
  };
  const queue = new ChangeQueue(onFlush, options.debounceMs ?? 200);

  const loaded = (async () => {
    await new Promise<void>((resolve) => setImmediate(resolve));
    const started = Date.now();
    project = loadProject(root, readFactsCache(root));
    saveCache();
    log(`loaded ${Object.keys(project.facts).length} files in ${Date.now() - started} ms`);
  })();
  const currentFindingIds = (): string[] => project?.graph.findings.map((f) => f.id) ?? [];
  const graphNow = async (): Promise<PublicGraph> => {
    await loaded;
    queue.flushNow();
    return toPublicGraph(project!.graph);
  };

  const server = await startServer({
    token,
    status: (): DaemonStatus => ({
      ok: true,
      root,
      pid: process.pid,
      version: DAEMON_VERSION,
      ready: project !== undefined,
      fileCount: project ? Object.keys(project.facts).length : 0,
      clients: server.clientCount(),
      seq,
    }),
    graph: graphNow,
    hello: async () => {
      const graph = await graphNow();
      return { type: 'graph', seq, graph };
    },
    touched: async ({ files, sessionId }) => {
      await loaded;
      const rels = files.map((f) => toProjectRel(root, f)).filter((r): r is string => r !== null);
      turns.touch(sessionId ?? 'default', rels, currentFindingIds());
      for (const rel of rels) queue.add(rel, 'claude');
    },
    startTurn: async (sessionId) => {
      await loaded;
      queue.flushNow();
      return turns.startTurn(sessionId, currentFindingIds());
    },
    findings: async (turnId, query) => {
      await loaded;
      queue.flushNow();
      return turns.newFindings(turnId, project!.graph.findings, query);
    },
    shutdown: () => {
      void stop('shutdown request');
    },
    activity: () => {
      lastActivity = Date.now();
    },
  });

  const info: DaemonInfo = { pid: process.pid, port: server.port, token, version: DAEMON_VERSION, root, startedAt: Date.now() };
  writeDaemonInfo(root, info);

  const ready = loaded.then(async () => {
    if (options.watch === false || stopping) return;
    const w = await watchProject(
      root,
      (e) => {
        if (e.kind === 'dir-removed') {
          const prefix = `${e.rel}/`;
          const known = [...Object.keys(project?.facts ?? {}), ...(project?.skipped ?? [])];
          for (const rel of known) if (rel.startsWith(prefix)) queue.add(rel, 'watcher');
        } else {
          queue.add(e.rel, 'watcher');
        }
      },
      (err) => log(`watcher error: ${String(err)}`),
    );
    if (stopping) {
      await w.close();
      return;
    }
    watcher = w;
    for (const rel of findDrift(project!)) queue.add(rel, 'watcher');
  });
  ready.catch((err: unknown) => {
    log(`start failed: ${err instanceof Error ? (err.stack ?? err.message) : String(err)}`);
    void stop('start failed');
  });

  timers.push(
    setInterval(() => {
      if (!project || !changedSinceReconcile) return;
      changedSinceReconcile = false;
      for (const rel of findDrift(project)) queue.add(rel, 'watcher');
    }, options.reconcileMs ?? 60_000),
  );
  timers.push(
    setInterval(
      () => {
        if (readDaemonInfo(root)?.pid !== process.pid) {
          void stop('replaced by another daemon');
          return;
        }
        if (server.clientCount() === 0 && Date.now() - lastActivity >= idleMs) void stop('idle');
      },
      Math.min(60_000, Math.max(50, Math.floor(idleMs / 4))),
    ),
  );

  function stop(reason = 'stop'): Promise<void> {
    if (stopping) return stopping;
    stopping = (async () => {
      log(`stopping: ${reason}`);
      for (const t of timers) clearInterval(t);
      if (cacheTimer) clearTimeout(cacheTimer);
      queue.flushNow();
      queue.dispose();
      await watcher?.close();
      await server.close();
      saveCache();
      removeDaemonInfo(root, process.pid);
      resolveDone(reason);
    })();
    return stopping;
  }

  return { info, ready, done, stop, project: () => project };
}

/** A daemon younger than this may still be busy with its first scan and is given the benefit of the doubt. */
export const STARTUP_GRACE_MS = 60_000;
const MAX_LOG_BYTES = 1_000_000;

const sleep = (ms: number): Promise<void> => new Promise((resolve) => setTimeout(resolve, ms));

export async function pingDaemon(info: DaemonInfo, timeoutMs = 1500): Promise<DaemonStatus | null> {
  try {
    const status = await request<DaemonStatus>(info, 'GET', '/api/status', undefined, timeoutMs);
    return status.ok && status.pid === info.pid ? status : null;
  } catch {
    return null;
  }
}

/** The daemon from daemon.json, if its process lives and it answers (or started less than a minute ago). */
export async function liveDaemon(root: string): Promise<DaemonInfo | null> {
  const info = readDaemonInfo(root);
  if (!info || !isPidAlive(info.pid)) return null;
  if (await pingDaemon(info)) return info;
  return Date.now() - info.startedAt < STARTUP_GRACE_MS ? info : null;
}

/** How to run this CLI again: node + bin.js, or node + tsx loader + bin.ts during development. */
export function selfCommand(): { command: string; args: string[] } {
  const here = fileURLToPath(import.meta.url);
  const ext = path.extname(here);
  const bin = path.join(path.dirname(here), '..', `bin${ext}`);
  if (ext === '.ts') {
    const loader = createRequire(import.meta.url).resolve('tsx');
    return { command: process.execPath, args: ['--import', pathToFileURL(loader).href, bin] };
  }
  return { command: process.execPath, args: [bin] };
}

/** Starts `mapskill daemon <root>` detached from this process, logging to .mapskill/daemon.log. */
export function spawnDaemon(root: string): void {
  ensureMapskillDir(root);
  const logFile = mapskillPath(root, 'daemon.log');
  let flags = 'a';
  try {
    if (fs.statSync(logFile).size > MAX_LOG_BYTES) flags = 'w';
  } catch {
    // no log yet
  }
  const log = fs.openSync(logFile, flags);
  try {
    const { command, args } = selfCommand();
    const child = spawn(command, [...args, 'daemon', root], {
      cwd: root,
      detached: true,
      stdio: ['ignore', log, log],
      windowsHide: true,
    });
    child.unref();
  } finally {
    fs.closeSync(log);
  }
}

/** Returns a running daemon for `root`, starting one if needed. Never throws: null means "carry on without Mapskill". */
export async function ensureDaemon(
  rootArg: string,
  options: { timeoutMs?: number; spawn?: (root: string) => void } = {},
): Promise<DaemonInfo | null> {
  const root = path.resolve(rootArg);
  try {
    const existing = await liveDaemon(root);
    if (existing) return existing;
    const old = readDaemonInfo(root);
    (options.spawn ?? spawnDaemon)(root);
    const deadline = Date.now() + (options.timeoutMs ?? 3000);
    let candidate: DaemonInfo | null = null;
    while (Date.now() < deadline) {
      await sleep(50);
      const info = readDaemonInfo(root);
      if (!info || info.pid === old?.pid || !isPidAlive(info.pid)) continue;
      candidate = info;
      if (await pingDaemon(info, 500)) return info;
    }
    return candidate;
  } catch {
    return null;
  }
}

import fs from 'node:fs';
import path from 'node:path';
import { ensureDaemon, liveDaemon, pingDaemon, request } from './daemon/client';
import { startDaemon } from './daemon/daemon';
import { acquireStartLock, isPidAlive, readDaemonInfo, releaseStartLock } from './daemon/info';

type Write = (s: string) => void;

const stdout: Write = (s) => process.stdout.write(s);
const stderr: Write = (s) => process.stderr.write(s);
const sleep = (ms: number): Promise<void> => new Promise((resolve) => setTimeout(resolve, ms));

function isDirectory(p: string): boolean {
  try {
    return fs.statSync(p).isDirectory();
  } catch {
    return false;
  }
}

/** `mapskill daemon [dir]`: runs the daemon in this process until it stops. */
export async function runDaemonCommand(dir: string, write: Write = stderr): Promise<number> {
  const root = path.resolve(dir);
  if (!isDirectory(root)) {
    write(`Not a folder: ${root}\n`);
    return 1;
  }
  if (await liveDaemon(root)) {
    write('Mapskill daemon already running\n');
    return 0;
  }
  if (!acquireStartLock(root)) {
    write('Another Mapskill daemon is starting\n');
    return 0;
  }
  const stamp = (line: string): void => write(`[${new Date().toISOString()}] ${line}\n`);
  const handle = await (async () => {
    try {
      return await startDaemon(root, { log: stamp });
    } finally {
      releaseStartLock(root);
    }
  })();
  stamp(`listening on http://127.0.0.1:${handle.info.port}`);
  const onSignal = (): void => {
    void handle.stop('signal');
  };
  process.once('SIGINT', onSignal);
  process.once('SIGTERM', onSignal);
  stamp(`stopped (${await handle.done})`);
  return 0;
}

/** `mapskill status [dir]`: starts the daemon if needed and prints where it listens. */
export async function runStatus(dir: string, write: Write = stdout): Promise<number> {
  const root = path.resolve(dir);
  if (!isDirectory(root)) {
    write(`Not a folder: ${root}\n`);
    return 1;
  }
  const info = await ensureDaemon(root, { timeoutMs: 10_000 });
  const status = info ? await pingDaemon(info, 5000) : null;
  if (!info || !status) {
    write(`Mapskill daemon is not answering. See ${path.join(root, '.mapskill', 'daemon.log')}\n`);
    return 1;
  }
  write(`Mapskill daemon: http://127.0.0.1:${info.port} · ${status.fileCount} files · ${status.ready ? 'ready' : 'starting'}\n`);
  return 0;
}

/** `mapskill stop [dir]`: asks the daemon to stop and waits until its process is gone. */
export async function runStop(dir: string, write: Write = stdout): Promise<number> {
  const root = path.resolve(dir);
  const info = readDaemonInfo(root);
  if (!info || !isPidAlive(info.pid)) {
    write('Mapskill daemon is not running\n');
    return 0;
  }
  try {
    await request(info, 'POST', '/api/shutdown');
  } catch {
    // it may already be stopping; wait below
  }
  const deadline = Date.now() + 5000;
  while (Date.now() < deadline && isPidAlive(info.pid)) await sleep(50);
  if (isPidAlive(info.pid)) {
    write('Mapskill daemon did not stop\n');
    return 1;
  }
  write('Mapskill daemon stopped\n');
  return 0;
}

const commands: Record<string, () => number | Promise<number>> = {
  scan: () => runScan(rest),
  status: () => runStatus(dir),
  stop: () => runStop(dir),
  daemon: () => runDaemonCommand(dir),
};

const run = command === undefined ? undefined : commands[command];
if (!run) {
  process.stderr.write(USAGE);
  process.exit(1);
}
Promise.resolve()
  .then(run)
  .then(
    (code) => process.exit(code),
    (err: unknown) => {
      process.stderr.write(`${err instanceof Error ? err.message : String(err)}\n`);
      process.exit(1);
    },
  );
```
