# Mapskill M4: kartvy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Användaren ser appen som en levande karta i webbläsaren och kan styra Claude därifrån.

- **Kartan:** zoner med sidor, server, byggstenar, data, delat, utanför och tester.
- **Liv:** delar som Claude ändrar pulserar.
- **Sidopanel:** förklarar varje del, visar fynden som frågor och de första 40 raderna kod.
- **Knappar:** Lås, Fråga, "Be Claude fixa" och "Det är okej".
- **Förfrågningar:** hamnar i en kö som skickas till Claude nästa gång användaren skriver till Claude.

**Architecture:** Ett nytt paket `packages/ui` (Vite, React 19, React Flow) byggs till statiska filer. Daemonen serverar dem på sin port.

- **Token:** kartan öppnas med `http://127.0.0.1:<port>/?t=<token>`. Sidan tar token från adressen, tar bort den från adressfältet och använder den för HTTP och WebSocket.
- **Placering:** rutornas placering är en egen deterministisk platsplacering. Varje ruta får en plats i sin zon, och platserna sparas i `.mapskill/layout.json`. En befintlig ruta flyttar sig därför aldrig när andra rutor kommer till eller försvinner.
- **Daemonen:** får HTTP-vägar för lås, förfrågningar, avfärdade fynd, placering och källkod. Ändringar pushas över WebSocket.
- **Avfärdade fynd:** filtreras bort i core när grafen byggs, så Stop-hooken och kartan ser samma sak.

**Tech Stack:** Node 22, pnpm-arbetsyta, TypeScript `~5.9.3`, Vitest. Nya beroenden i `packages/ui`:

## Global Constraints

- Node `>=22.12`. pnpm `>=10`. `typescript` låst till `~5.9.3`.
- **Inga native-beroenden:** inga i `@mapskill/core` eller `mapskill` (CLI-paketet), och inga nya körberoenden där alls. Kartvyns beroenden ligger bara i `packages/ui` och paketeras till statiska filer. Användaren behöver dem aldrig installerade.
- **Inget nätverk utåt:** ingen nätverkstrafik utöver `127.0.0.1` (inte heller från kartvyn: inga CDN:er, typsnitt eller bilder utifrån), ingen LLM, ingen telemetri.
- **Skrivningar:** Mapskill skriver bara i `.mapskill/` och, en gång, i en befintlig `.gitignore`. Nya filer: `requests.json`, `dismissed.json` och `layout.json` i `.mapskill/`.
- **Core:** `@mapskill/core` har inga sidoeffekter utöver filläsning. Kartvyn importerar bara `@mapskill/core/client`, som inte får dra in TypeScript-kompilatorn eller `node:`-moduler.
- **Hooks:** ingen fil under `packages/cli/src/hooks/` får göra en körtidsimport av `@mapskill/core`.
- **Säkerhet:**
  - Varje `/api/*`-anrop kräver `x-mapskill-token`. WebSocket kräver hello med token inom 2 s.
  - Host-headern måste vara `127.0.0.1:<port>` eller `localhost:<port>`.
  - Statiska filer (kartvyns HTML, JS, CSS) får serveras utan token. De innehåller inga projektdata.
  - Statiska svar har headers `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self' ws://127.0.0.1:* ws://localhost:*; frame-ancestors 'none'`, `Referrer-Policy: no-referrer` och `X-Content-Type-Options: nosniff`.
- **Källkod i panelen:** `GET /api/source` lämnar bara ut filer som finns bland projektets källfiler i grafen, aldrig `.env*`. Högst 200 rader per anrop.
- **Text i kartan:** all text som visas för användaren finns på engelska och svenska (beslut B6). Språket följer webbläsaren (`sv*` ger svenska) och kan bytas i sidhuvudet. Fynd har redan `{ en, sv }`.
- **Text till Claude:** förfrågningar som skickas till Claude skrivs på användarens valda språk. Svenska exempel ska vara på enkel svenska.
- **Tillgänglighet:**
  - Varje ruta kan nås med Tab och öppnas med Enter.
  - Färg är aldrig enda signalen: fynd har ikon och text, och lås har ikon och text.
  - Synlig fokusram.
  - `prefers-reduced-motion` stänger av pulsen och ersätter den med en ram.
- **Tema:** ljust och mörkt tema efter systemet (`prefers-color-scheme`).
- **Stabil placering:** en befintlig ruta byter inte plats inom sin zon när rutor läggs till, tas bort eller ändras. När en fil bara ändras (inga rutor tillkommer eller försvinner) flyttar ingen ruta alls.
- **Tider:**
  - En ruta pulserar i 10 sekunder efter att filen ändrats.
  - En ruta har en tunn ram om filen ändrats under det pågående varvet.
  - WebSocket återansluter med backoff 0,5 → 1 → 2 → 4 → 8 sekunder (sedan 8).
- **Kön:** förfrågningar har högst 2 000 tecken text. Kön sparar högst 200 poster; äldst skickade och avbrutna tas bort först.
- **Modulsystem:** ESM, importer utan filändelse i källkoden, `moduleResolution: "Bundler"`.
- **Commits:** varje commit-meddelande avslutas med raden `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Lägg aldrig till `.superpowers/`, `plugin/dist/` eller `packages/ui/dist/` i git.

Regler för avfärdade fynd:
- **Kodhash:** `findingCodeHash` är `sha1` av fyndets filers innehållshash (`files[p]?.hash ?? ''`) i fyndets filordning (som redan är sorterad), sammanfogade med `|`.
- **Filtrering:** `buildGraph` tar bort ett fynd vars id finns i `project.dismissed` och vars kodhash är oförändrad. Det sker innan hälsan räknas ut, så hälsan stiger när ett fynd avfärdas.
- **När koden ändras:** ändras någon av filerna visas fyndet igen. Posten i `dismissed` ligger kvar men matchar inte längre. Daemonen städar bort sådana poster (Task 3).
- **`setDismissed`:** sätter listan, bygger om grafen och returnerar `ChangeResult` med skillnaden (`reloaded: false`).
- **Omladdning:** `applyFileChanges` behåller `dismissed` vid omladdning (projektinställningsfil ändrad), genom att skicka med den till `loadProject`.

```ts
/** Relative imports of a module, followed recursively; fails on typescript or node: imports. */
function walk(file: string, seen = new Set<string>()): Set<string> {
  if (seen.has(file)) return seen;
  seen.add(file);
  const text = fs.readFileSync(file, 'utf8');
  for (const m of text.matchAll(/^(?:import|export)\s+(type\s+)?[^'"]*from\s+'([^']+)'/gm)) {
    const typeOnly = Boolean(m[1]);
    const spec = m[2];
    if (typeOnly) continue;
    if (spec === 'typescript' || spec.startsWith('node:')) throw new Error(`${file} imports ${spec}`);
    if (spec.startsWith('.')) walk(path.resolve(path.dirname(file), `${spec}.ts`), seen);
  }
  return seen;
}
```

```ts
// requests.ts
export const MAX_REQUEST_CHARS = 2000;
export const MAX_REQUESTS = 200;
export class RequestQueue {
  constructor(root: string, now?: () => number);
  list(): MapRequest[];                       // newest last
  add(input: { kind: RequestKind; text: string; nodeId?: string; findingId?: string }): MapRequest; // throws RangeError for empty or too long text
  cancel(id: string): boolean;                // only pending ones; true when changed
  claimPending(): MapRequest[];               // all pending, oldest first, now marked sent
}
// state-files.ts
export function readDismissed(root: string): Record<string, string>;
export function writeDismissed(root: string, dismissed: Record<string, string>): void;
export function readLayout(root: string): LayoutFile;          // { version: 1, slots: {} } when missing or broken
export function writeLayout(root: string, layout: LayoutFile): void;
```

Regler:
- **Var kön sparas:** `RequestQueue` läser `.mapskill/requests.json` (`{ "version": 1, "requests": [...] }`) när den skapas och skriver hela filen atomärt efter varje ändring. En saknad eller trasig fil ger en tom kö, och en trasig fil skrivs över först vid nästa ändring.
- **Id:** `randomUUID()`.
- **Rensning:** när kön har fler än 200 poster tas skickade och avbrutna bort först, äldst först. Väntande poster tas aldrig bort av rensningen.
- **Text:** trimmas, och tom text eller mer än 2 000 tecken ger `RangeError`.
- **Placering:** `readLayout` godtar bara `slots` vars värden är heltal ≥ 0. Andra poster hoppas över.
- **Avfärdade fynd:** `readDismissed` godtar bara strängvärden.

```ts
// packages/cli/src/daemon/requests.ts
import { randomUUID } from 'node:crypto';
import type { MapRequest, RequestKind } from '@mapskill/core';
import { ensureMapskillDir, mapskillPath, readJson, writeJsonAtomic } from './paths';

export const MAX_REQUEST_CHARS = 2000;
export const MAX_REQUESTS = 200;
const FILE = 'requests.json';
const KINDS: RequestKind[] = ['explain', 'fix', 'custom'];

function valid(r: unknown): r is MapRequest {
  const x = r as MapRequest;
  return (
    typeof x === 'object' && x !== null && typeof x.id === 'string' && typeof x.text === 'string' &&
    KINDS.includes(x.kind) && ['pending', 'sent', 'cancelled'].includes(x.status) && typeof x.createdAt === 'number'
  );
}

/** The map's request queue in .mapskill/requests.json: written by the map, read by the UserPromptSubmit hook via the daemon. */
export class RequestQueue {
  private requests: MapRequest[];

  constructor(
    private readonly root: string,
    private readonly now: () => number = Date.now,
  ) {
    const data = readJson<{ requests?: unknown[] }>(mapskillPath(root, FILE));
    this.requests = Array.isArray(data?.requests) ? data.requests.filter(valid) : [];
  }

  list(): MapRequest[] {
    return this.requests.map((r) => ({ ...r }));
  }

  add(input: { kind: RequestKind; text: string; nodeId?: string; findingId?: string }): MapRequest {
    const text = input.text.trim();
    if (text === '' || text.length > MAX_REQUEST_CHARS) throw new RangeError(`text must be 1-${MAX_REQUEST_CHARS} characters`);
    const request: MapRequest = {
      id: randomUUID(),
      kind: input.kind,
      text,
      ...(input.nodeId ? { nodeId: input.nodeId } : {}),
      ...(input.findingId ? { findingId: input.findingId } : {}),
      createdAt: this.now(),
      status: 'pending',
    };
    this.requests.push(request);
    this.prune();
    this.save();
    return { ...request };
  }

  cancel(id: string): boolean {
    const r = this.requests.find((x) => x.id === id && x.status === 'pending');
    if (!r) return false;
    r.status = 'cancelled';
    this.save();
    return true;
  }

  /** Returns every pending request (oldest first) and marks them sent. */
  claimPending(): MapRequest[] {
    const pending = this.requests.filter((r) => r.status === 'pending');
    if (pending.length === 0) return [];
    const at = this.now();
    for (const r of pending) {
      r.status = 'sent';
      r.sentAt = at;
    }
    this.save();
    return pending.map((r) => ({ ...r }));
  }

  private prune(): void {
    while (this.requests.length > MAX_REQUESTS) {
      const at = this.requests.findIndex((r) => r.status !== 'pending');
      if (at < 0) break;
      this.requests.splice(at, 1);
    }
  }

  private save(): void {
    ensureMapskillDir(this.root);
    writeJsonAtomic(mapskillPath(this.root, FILE), { version: 1, requests: this.requests });
  }
}
```

```ts
import type { LayoutFile } from '@mapskill/core';
import { ensureMapskillDir, mapskillPath, readJson, writeJsonAtomic } from './paths';

export function readDismissed(root: string): Record<string, string> {
  const data = readJson<{ dismissed?: Record<string, unknown> }>(mapskillPath(root, 'dismissed.json'));
  const out: Record<string, string> = {};
  for (const [id, hash] of Object.entries(data?.dismissed ?? {})) if (typeof hash === 'string') out[id] = hash;
  return out;
}

export function writeDismissed(root: string, dismissed: Record<string, string>): void {
  ensureMapskillDir(root);
  writeJsonAtomic(mapskillPath(root, 'dismissed.json'), { version: 1, dismissed });
}

export function readLayout(root: string): LayoutFile {
  const data = readJson<{ slots?: Record<string, unknown> }>(mapskillPath(root, 'layout.json'));
  const slots: Record<string, number> = {};
  for (const [id, slot] of Object.entries(data?.slots ?? {})) {
    if (typeof slot === 'number' && Number.isInteger(slot) && slot >= 0) slots[id] = slot;
  }
  return { version: 1, slots };
}

export function writeLayout(root: string, layout: LayoutFile): void {
  ensureMapskillDir(root);
  writeJsonAtomic(mapskillPath(root, 'layout.json'), { version: 1, slots: layout.slots });
```

```ts
export const SECURITY_HEADERS: Record<string, string> = {
  'content-security-policy':
    "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; " +
    "connect-src 'self' ws://127.0.0.1:* ws://localhost:*; frame-ancestors 'none'",
  'referrer-policy': 'no-referrer',
  'x-content-type-options': 'nosniff',

/** True for requests the map view's static files answer: GET/HEAD outside /api/ and /ws. */
export function isStaticRequest(method: string | undefined, pathname: string): boolean {
  return (method === 'GET' || method === 'HEAD') && !pathname.startsWith('/api/') && pathname !== '/ws';
}

/** Answers a static request from `uiDir`. Paths without an extension get index.html (the map is one page). */
export function serveStatic(uiDir: string | null, req: http.IncomingMessage, res: http.ServerResponse, pathname: string): void {
  const plain = (status: number, text: string): void => {
    res.writeHead(status, { ...SECURITY_HEADERS, 'content-type': 'text/plain; charset=utf-8' });
    res.end(text);
  };
  if (!uiDir) return plain(404, 'Mapskill map view is not built. Run: pnpm build:plugin\n');
  let decoded: string;
  try {
    decoded = decodeURIComponent(pathname);
  } catch {
    return plain(404, 'not found\n');
  }
  const wantsPage = path.extname(decoded) === '';
  const file = path.resolve(uiDir, '.' + (wantsPage ? '/index.html' : decoded));
  const rootWithSep = path.resolve(uiDir) + path.sep;
  if (!file.startsWith(rootWithSep)) return plain(404, 'not found\n');
  let body: Buffer;
  try {
    body = fs.readFileSync(file);
  } catch {
    return plain(404, 'not found\n');
  }
  const rel = path.relative(uiDir, file).split(path.sep).join('/');
  res.writeHead(200, {
    ...SECURITY_HEADERS,
    'content-type': TYPES[path.extname(file).toLowerCase()] ?? 'application/octet-stream',
    'cache-control': rel.startsWith('assets/') ? 'public, max-age=31536000, immutable' : 'no-cache',
    'content-length': body.length,
  });
  res.end(req.method === 'HEAD' ? undefined : body);
}
```

```ts
// packages/cli/src/open-command.ts
import { spawn } from 'node:child_process';
import path from 'node:path';
import { ensureDaemon } from './daemon/client';

type Write = (s: string) => void;

export function mapUrl(info: { port: number; token: string }): string {
  return `http://127.0.0.1:${info.port}/?t=${info.token}`;
}

/** Opens a URL in the default browser. Best effort: errors are ignored. */
export function openInBrowser(url: string): void {
  const [command, args] =
    process.platform === 'win32'
      ? ['rundll32', ['url.dll,FileProtocolHandler', url]]
      : process.platform === 'darwin'
        ? ['open', [url]]
        : ['xdg-open', [url]];
  try {
    const child = spawn(command, args, { detached: true, stdio: 'ignore', windowsHide: true });
    child.on('error', () => {});
    child.unref();
  } catch {
    // no browser available: the printed address is enough
  }
}

/** `mapskill open [dir] [--no-browser]`: starts the daemon if needed, prints the map address and opens it. */
export async function runOpen(
  argv: string[],
  deps: { open?: (url: string) => void; write?: Write } = {},
): Promise<number> {
  const write = deps.write ?? ((s: string) => void process.stdout.write(s));
  const noBrowser = argv.includes('--no-browser');
  const dir = argv.find((a) => !a.startsWith('--')) ?? '.';
  const root = path.resolve(dir);
  const info = await ensureDaemon(root, { timeoutMs: 10_000 });
  if (!info) {
    write(`Mapskill daemon is not answering. See ${path.join(root, '.mapskill', 'daemon.log')}\n`);
    return 1;
  }
  const url = mapUrl(info);
  write(`Mapskill map: ${url}\n`);
  if (!noBrowser) (deps.open ?? openInBrowser)(url);
  return 0;
}
```

```ts
    return ALLOW;
  }
  const { requests } = await request<{ requests: MapRequest[] }>(info, 'POST', '/api/requests/claim', { sessionId: input.session_id ?? 'default' }, left);
  if (requests.length === 0) return ALLOW;
  return {
    exitCode: 0,
    stdout: JSON.stringify({ hookSpecificOutput: { hookEventName: 'UserPromptSubmit', additionalContext: formatRequests(requests) } }),
  };
```

- **Reducern:**
  - **`graph`:** ersätter grafen och `seq`, och sätter `needsResync: false`.
  - **`delta`:** tillämpas bara om `seq === state.seq + 1`. Annars sätts `needsResync: true` och grafen lämnas orörd.

```ts
// packages/ui/src/api.ts
import type { LayoutFile, LocksAnswer, MapRequest, PublicGraph, RequestKind, SourceAnswer } from '@mapskill/core/client';

const TOKEN_KEY = 'mapskill-token';

/** Reads the token from ?t=, remembers it for reloads, and returns the address without it. */
export function takeToken(
  location: { search: string; pathname: string; hash: string },
  storage: Pick<Storage, 'getItem' | 'setItem'>,
): { token: string | null; cleanUrl: string | null } {
  const params = new URLSearchParams(location.search);
  const fromUrl = params.get('t');
  if (fromUrl) {
    storage.setItem(TOKEN_KEY, fromUrl);
    params.delete('t');
    const rest = params.toString();
    return { token: fromUrl, cleanUrl: `${location.pathname}${rest ? `?${rest}` : ''}${location.hash}` };
  }
  return { token: storage.getItem(TOKEN_KEY), cleanUrl: null };
}

export class ApiError extends Error {
  constructor(
    readonly status: number,
    message: string,
  ) {
    super(message);
  }
}

export class Api {
  constructor(
    private readonly token: string,
    private readonly base = '',
  ) {}

  private async call<T>(method: 'GET' | 'POST', path: string, body?: unknown): Promise<T> {
    const res = await fetch(`${this.base}${path}`, {
      method,
      headers: { 'x-mapskill-token': this.token, ...(body === undefined ? {} : { 'content-type': 'application/json' }) },
      body: body === undefined ? undefined : JSON.stringify(body),
    });
    const json = (await res.json().catch(() => ({}))) as T & { error?: string };
    if (!res.ok) throw new ApiError(res.status, json.error ?? res.statusText);
    return json;
  }

  graph = (): Promise<PublicGraph> => this.call('GET', '/api/graph');
  locks = (): Promise<LocksAnswer> => this.call('GET', '/api/locks');
  setLock = (nodeId: string, locked: boolean): Promise<LocksAnswer> => this.call('POST', '/api/locks', { nodeId, locked });
  requests = async (): Promise<MapRequest[]> => (await this.call<{ requests: MapRequest[] }>('GET', '/api/requests')).requests;
  addRequest = async (input: { kind: RequestKind; text: string; nodeId?: string; findingId?: string }): Promise<MapRequest> =>
    (await this.call<{ request: MapRequest }>('POST', '/api/requests', input)).request;
  cancelRequest = async (id: string): Promise<MapRequest[]> =>
    (await this.call<{ requests: MapRequest[] }>('POST', '/api/requests/cancel', { id })).requests;
  dismiss = async (findingId: string): Promise<void> => {
    await this.call('POST', '/api/dismiss', { findingId });
  };
  layout = (): Promise<LayoutFile> => this.call('GET', '/api/layout');
  saveLayout = async (slots: Record<string, number>): Promise<void> => {
```

```ts
// packages/ui/src/reducer.ts
import { applyDelta, type LockInfo, type MapRequest, type PublicGraph, type ServerMessage } from '@mapskill/core/client';

export const PULSE_MS = 10_000;
const MAX_ACTIVITY = 50;

export interface Activity {
  at: number;
  files: { path: string; by: 'claude' | 'watcher' }[];
}

export interface MapState {
  status: 'connecting' | 'live' | 'reconnecting';
  graph: PublicGraph | null;
  seq: number;
  activity: Activity[];
  pulseUntil: Record<string, number>;
  touchedThisTurn: string[];
  turnStartedAt: number | null;
  requests: MapRequest[];
  locks: LockInfo[];
  lockedFiles: string[];
  needsResync: boolean;
}

export const initialState: MapState = {
  status: 'connecting',
  graph: null,
  seq: 0,
  activity: [],
  pulseUntil: {},
  touchedThisTurn: [],
  turnStartedAt: null,
  requests: [],
  locks: [],
  lockedFiles: [],
  needsResync: false,
};

export type Action =
  | { type: 'server'; message: ServerMessage; now: number }
  | { type: 'status'; status: MapState['status'] }
  | { type: 'requests'; requests: MapRequest[] }
  | { type: 'locks'; locks: LockInfo[]; lockedFiles: string[] };

function onServer(state: MapState, m: ServerMessage): MapState {
  switch (m.type) {
    case 'graph':
      return { ...state, graph: m.graph, seq: m.seq, needsResync: false, status: 'live' };
    case 'delta':
      if (!state.graph || m.seq !== state.seq + 1) return { ...state, needsResync: true };
      return { ...state, graph: applyDelta(state.graph, m.delta), seq: m.seq };
    case 'activity': {
      const pulseUntil = { ...state.pulseUntil };
      for (const f of m.files) pulseUntil[f.path] = m.at + PULSE_MS;
      const touched = [...new Set([...state.touchedThisTurn, ...m.files.map((f) => f.path)])].sort();
      return { ...state, activity: [{ at: m.at, files: m.files }, ...state.activity].slice(0, MAX_ACTIVITY), pulseUntil, touchedThisTurn: touched };
    }
    case 'turn':
      return { ...state, touchedThisTurn: [], turnStartedAt: m.at };
    case 'requests':
      return { ...state, requests: m.requests };
    case 'locks':
      return { ...state, locks: m.locks, lockedFiles: m.lockedFiles };
  }
}

export function reduce(state: MapState, action: Action): MapState {
  switch (action.type) {
    case 'server':
      return onServer(state, action.message);
    case 'status':
      return { ...state, status: action.status };
    case 'requests':
      return { ...state, requests: action.requests };
    case 'locks':
      return { ...state, locks: action.locks, lockedFiles: action.lockedFiles };
  }
}
```

```ts
// packages/ui/src/connection.ts
import type { ServerMessage } from '@mapskill/core/client';
import { useEffect, useReducer, useRef } from 'react';
import { Api } from './api';
import { initialState, reduce, type Action, type MapState } from './reducer';

const BACKOFF_MS = [500, 1000, 2000, 4000, 8000];

/** Keeps a WebSocket to the daemon open (with backoff) and turns its messages into map state. */
export function useMapConnection(token: string): { state: MapState; dispatch: (a: Action) => void; api: Api } {
  const [state, dispatch] = useReducer(reduce, initialState);
  const apiRef = useRef(new Api(token));
  const socketRef = useRef<WebSocket | null>(null);

  useEffect(() => {
    let attempt = 0;
    let timer: ReturnType<typeof setTimeout> | undefined;
    let stopped = false;
    const api = apiRef.current;
    const refreshSideData = (): void => {
      api.locks().then((l) => dispatch({ type: 'locks', locks: l.locks, lockedFiles: l.lockedFiles }), () => {});
      api.requests().then((r) => dispatch({ type: 'requests', requests: r }), () => {});
    };
    const connect = (): void => {
      const scheme = location.protocol === 'https:' ? 'wss' : 'ws';
      const ws = new WebSocket(`${scheme}://${location.host}/ws`);
      socketRef.current = ws;
      ws.onopen = () => {
        ws.send(JSON.stringify({ type: 'hello', token }));
        refreshSideData();
      };
      ws.onmessage = (e) => {
        const message = JSON.parse(String(e.data)) as ServerMessage;
        if (message.type === 'graph') attempt = 0;
        dispatch({ type: 'server', message, now: Date.now() });
      };
      ws.onclose = () => {
        if (stopped) return;
        dispatch({ type: 'status', status: 'reconnecting' });
        const wait = BACKOFF_MS[Math.min(attempt, BACKOFF_MS.length - 1)];
        attempt += 1;
        timer = setTimeout(connect, wait);
      };
    };
    connect();
    const onFocus = (): void => refreshSideData();
    window.addEventListener('focus', onFocus);
    return () => {
      stopped = true;
      clearTimeout(timer);
      window.removeEventListener('focus', onFocus);
      socketRef.current?.close();
    };
  }, [token]);

  // A delta arrived out of order: drop the socket; the reconnect starts with a full graph.
  useEffect(() => {
    if (state.needsResync) socketRef.current?.close();
  }, [state.needsResync]);

  return { state, dispatch, api: apiRef.current };
}
```

Vid `needsResync` stängs anslutningen och `onclose` återansluter efter första backoff-steget. Det räcker: daemonen skickar hela grafen vid hello.

Regler för platserna:
- **`assignSlots`, zon för zon:**
  - En ruta som har en sparad plats behåller den.
  - Krockar två rutor om samma plats (en trasig fil), behåller den med lägst id platsen, och den andra räknas som ny.
  - Nya rutor tar, i id-ordning, den lägsta lediga platsen.
  - Rutor som försvunnit släpper sin plats, men ingen annan ruta flyttar in automatiskt förrän en ny ruta kommer.
  - Resultatet innehåller bara rutor som finns nu.
- **`layoutMap`:**
  - **Placering i zonen:** rutans plats `s` i en zon med `c` kolumner ger `x = padding + (s % c) * (width + gapX)` och `y = header + floor(s / c) * (height + gapY)`, relativt zonens ruta.
  - **Zonens storlek:** antalet rader är `max(1, ceil((störstaPlats + 1) / c))`. Bredden är `2*padding + c*width + (c-1)*gapX`, och höjden är `header + rader*(height+gapY) - gapY + padding`.
  - **Hopfällda zoner:** en hopfälld zon har höjden `header + padding` och inga positioner för sina rutor.
  - **Var zonerna står:** bara zoner med minst en ruta visas. De staplas i sin kolumn med `gap` emellan. Kolumn 2 börjar på x = bredaste zonen i kolumn 1 + `columnGap`.
- **Stabilitet:** en rutas position relativt sin zon beror bara på dess plats. Ändras en fil utan att rutor tillkommer eller försvinner, blir hela resultatet identiskt.

Regler för vy-modellen:
- **`partFlags`, per ruta med fil:**
  - `pulsing` när `pulseUntil[fil] > now`
  - `touched` när filen finns i `touchedThisTurn`
  - `locked` när filen finns i `lockedFiles`
  - Rutor utan fil får `false` på alla tre.
- **`visibleEdges`:**
  - med `showAll`, alla kanter
  - annars, med en vald ruta, kanterna in till och ut från den
  - annars inga
- **`related`:** `usedBy` är rutorna med en `uses`- eller `tests`-kant in till rutan. `uses` är målen för alla kanter ut från rutan. Båda listorna är unika och sorterade på etikett.
- **`projectHealth`:** avrundat medel av `health` för alla rutor, eller 10 när det inte finns några.
- **`activityLine`:**
  - **Vem:** `t(lang, 'activityLine', { who, files })`, där `who` är Claude om någon fil är `by: 'claude'`, annars `byYou`.
  - **Vilka filer:** rutornas etiketter för filerna (filnamnet om ingen ruta finns), högst tre, sedan `+N`.

```ts
// packages/ui/src/layout.ts
import type { Zone } from '@mapskill/core/client';

export const ZONE_COLUMNS: Zone[][] = [
  ['pages', 'blocks', 'shared'],
  ['server', 'data', 'outside', 'tests'],
];
export const COLS_PER_ZONE: Record<Zone, number> = { pages: 3, blocks: 3, shared: 3, server: 2, data: 2, outside: 2, tests: 2 };
export const CARD = { width: 200, height: 48, gapX: 12, gapY: 10 } as const;
export const ZONE_BOX = { padding: 16, header: 36, gap: 24, columnGap: 40 } as const;

const byId = (a: { id: string }, b: { id: string }): number => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0);

/** Keeps every part's saved slot; new parts take the lowest free slots of their zone, in id order. */
export function assignSlots(nodes: { id: string; zone: Zone }[], saved: Record<string, number>): Record<string, number> {
  const out: Record<string, number> = {};
  const zones = new Map<Zone, { id: string; zone: Zone }[]>();
  for (const node of nodes) zones.set(node.zone, [...(zones.get(node.zone) ?? []), node]);
  for (const list of zones.values()) {
    const sorted = [...list].sort(byId);
    const taken = new Set<number>();
    const fresh: string[] = [];
    for (const { id } of sorted) {
      const slot = saved[id];
      if (slot !== undefined && !taken.has(slot)) {
        taken.add(slot);
        out[id] = slot;
      } else fresh.push(id);
    }
    let next = 0;
    for (const id of fresh) {
      while (taken.has(next)) next++;
      taken.add(next);
      out[id] = next;
    }
  }
  return out;
}

export interface ZoneBox {
  zone: Zone;
  x: number;
  y: number;
  width: number;
  height: number;
  count: number;
  collapsed: boolean;
}

export interface MapLayout {
  zones: ZoneBox[];
  /** Part positions relative to their zone box (React Flow child positions). */
  positions: Record<string, { x: number; y: number }>;
}

export function layoutMap(nodes: { id: string; zone: Zone }[], slots: Record<string, number>, collapsed: ReadonlySet<Zone>): MapLayout {
  const positions: Record<string, { x: number; y: number }> = {};
  const zones: ZoneBox[] = [];
  const byZone = new Map<Zone, string[]>();
  for (const node of nodes) byZone.set(node.zone, [...(byZone.get(node.zone) ?? []), node.id]);
  let columnX = 0;
  for (const column of ZONE_COLUMNS) {
    let y = 0;
    let widest = 0;
    for (const zone of column) {
      const ids = byZone.get(zone);
      if (!ids || ids.length === 0) continue;
      const cols = COLS_PER_ZONE[zone];
      const width = 2 * ZONE_BOX.padding + cols * CARD.width + (cols - 1) * CARD.gapX;
      const isCollapsed = collapsed.has(zone);
      let height = ZONE_BOX.header + ZONE_BOX.padding;
      if (!isCollapsed) {
        const maxSlot = Math.max(...ids.map((id) => slots[id] ?? 0));
        const rows = Math.max(1, Math.ceil((maxSlot + 1) / cols));
        height = ZONE_BOX.header + rows * (CARD.height + CARD.gapY) - CARD.gapY + ZONE_BOX.padding;
        for (const id of ids) {
          const s = slots[id] ?? 0;
          positions[id] = {
            x: ZONE_BOX.padding + (s % cols) * (CARD.width + CARD.gapX),
            y: ZONE_BOX.header + Math.floor(s / cols) * (CARD.height + CARD.gapY),
          };
        }
      }
      zones.push({ zone, x: columnX, y, width, height, count: ids.length, collapsed: isCollapsed });
      y += height + ZONE_BOX.gap;
      widest = Math.max(widest, width);
    }
    if (widest > 0) columnX += widest + ZONE_BOX.columnGap;
  }
  return { zones, positions };
}
```

```ts
export function partFlags(
  graph: PublicGraph,
  s: Pick<MapState, 'pulseUntil' | 'touchedThisTurn' | 'lockedFiles'>,
  now: number,
): Record<string, { pulsing: boolean; touched: boolean; locked: boolean }> {
  const touched = new Set(s.touchedThisTurn);
  const locked = new Set(s.lockedFiles);
  const out: Record<string, { pulsing: boolean; touched: boolean; locked: boolean }> = {};
  for (const n of graph.nodes) {
    const f = n.file;
    out[n.id] = {
      pulsing: f !== undefined && (s.pulseUntil[f] ?? 0) > now,
      touched: f !== undefined && touched.has(f),
      locked: f !== undefined && locked.has(f),
    };
  }
  return out;
}

/** When the next pulse ends (to re-render then), or null when nothing pulses. */
export function nextPulseEnd(pulseUntil: Record<string, number>, now: number): number | null {
  const future = Object.values(pulseUntil).filter((t) => t > now);
  return future.length ? Math.min(...future) : null;
}

export function visibleEdges(graph: PublicGraph, selectedId: string | null, showAll: boolean): MapEdge[] {
  if (showAll) return graph.edges;
  if (!selectedId) return [];
  return graph.edges.filter((e) => e.from === selectedId || e.to === selectedId);
}

export function related(graph: PublicGraph, id: string): { usedBy: MapNode[]; uses: MapNode[] } {
  const node = (nid: string): MapNode | undefined => graph.nodes.find((n) => n.id === nid);
  const unique = (ids: string[]): MapNode[] =>
    [...new Set(ids)].map(node).filter((n): n is MapNode => n !== undefined).sort(byLabel);
  return {
    usedBy: unique(graph.edges.filter((e) => e.to === id && (e.kind === 'uses' || e.kind === 'tests')).map((e) => e.from)),
    uses: unique(graph.edges.filter((e) => e.from === id).map((e) => e.to)),
  };
}

export function projectHealth(graph: PublicGraph): number {
  if (graph.nodes.length === 0) return 10;
  const sum = graph.nodes.reduce((s, n) => s + (graph.health[n.id] ?? 10), 0);
  return Math.round(sum / graph.nodes.length);
}

export function activityLine(a: Activity, graph: PublicGraph | null, lang: Lang): string {
  const name = (file: string): string => graph?.nodes.find((n) => n.file === file)?.label ?? file.split('/').pop() ?? file;
  const names = [...new Set(a.files.map((f) => name(f.path)))];
  const shown = names.slice(0, 3).join(', ') + (names.length > 3 ? ` +${names.length - 3}` : '');
  const who = a.files.some((f) => f.by === 'claude') ? t(lang, 'byClaude') : t(lang, 'byYou');
  return t(lang, 'activityLine', { who, files: shown });
}
```

```ts
// packages/ui/src/slots.ts
import type { PublicGraph } from '@mapskill/core/client';
import { useEffect, useMemo, useRef, useState } from 'react';
import type { Api } from './api';
import { assignSlots } from './layout';

const SAVE_DELAY_MS = 1000;
const same = (a: Record<string, number>, b: Record<string, number>): boolean => {
  const ka = Object.keys(a);
  return ka.length === Object.keys(b).length && ka.every((k) => a[k] === b[k]);
};

/** Slots for every part: saved ones from .mapskill/layout.json, new ones assigned and saved after a quiet second. */
export function useSlots(graph: PublicGraph | null, api: Api): Record<string, number> {
  const [saved, setSaved] = useState<Record<string, number> | null>(null);
  const lastSaved = useRef<Record<string, number>>({});
  useEffect(() => {
    api.layout().then(
      (l) => {
        lastSaved.current = l.slots;
        setSaved(l.slots);
      },
      () => setSaved({}),
    );
  }, [api]);
  // Saved slots plus those saved during this session, so a part keeps its slot after it was first assigned.
  const slots = useMemo(
    () => (graph ? assignSlots(graph.nodes, { ...(saved ?? {}), ...lastSaved.current }) : {}),
    [graph, saved],
  );
  useEffect(() => {
    if (saved === null || !graph || same(slots, lastSaved.current)) return;
    const timer = setTimeout(() => {
      lastSaved.current = slots;
      api.saveLayout(slots).catch(() => {});
    }, SAVE_DELAY_MS);
    return () => clearTimeout(timer);
  }, [slots, saved, graph, api]);
  return slots;
}
```

```tsx
// packages/ui/src/components/CodeView.tsx
import { useEffect, useState } from 'react';
import type { Api } from '../api';
import { t, type Lang } from '../i18n';

const LINES = 40;

type Highlighter = { codeToHtml(code: string, options: { lang: string; themes: { light: string; dark: string } }): string };
let highlighter: Promise<Highlighter | null> | null = null;

/** Shiki with only tsx/typescript and two themes, loaded on first use. Null when it cannot load. */
function loadHighlighter(): Promise<Highlighter | null> {
  // The JavaScript regex engine avoids WebAssembly, which the page's Content-Security-Policy does not allow.
  highlighter ??= Promise.all([import('shiki'), import('shiki/engine/javascript')])
    .then(
      ([shiki, js]) =>
        shiki.createHighlighter({
          themes: ['github-light', 'github-dark'],
          langs: ['tsx', 'typescript'],
          engine: js.createJavaScriptRegexEngine(),
        }) as Promise<Highlighter>,
    )
    .catch(() => null);
  return highlighter;
}

export function CodeView({ api, file, start, lang }: { api: Api; file: string; start: number; lang: Lang }) {
  const [lines, setLines] = useState<string[] | null>(null);
  const [html, setHtml] = useState<string | null>(null);
  const [failed, setFailed] = useState(false);
  useEffect(() => {
    let alive = true;
    setLines(null);
    setHtml(null);
    setFailed(false);
    api.source(file, start, start + LINES - 1).then(
      async (answer) => {
        if (!alive) return;
        setLines(answer.lines);
        const h = await loadHighlighter();
        if (!alive || !h) return;
        const language = file.endsWith('.tsx') || file.endsWith('.jsx') ? 'tsx' : 'typescript';
        setHtml(h.codeToHtml(answer.lines.join('\n'), { lang: language, themes: { light: 'github-light', dark: 'github-dark' } }));
      },
      () => alive && setFailed(true),
    );
    return () => {
      alive = false;
    };
  }, [api, file, start]);
  if (failed) return <p className="muted">{t(lang, 'codeFailed')}</p>;
  if (!lines) return <p className="muted">{t(lang, 'codeLoading')}</p>;
  // Shiki's HTML is generated locally from our own source text and escapes it; it carries no scripts.
  if (html) return <div className="code" style={{ counterReset: `line ${start - 1}` }} dangerouslySetInnerHTML={{ __html: html }} />;
  return (
    <pre className="code plain">
      {lines.map((l, i) => (
        <div key={i}>
          <span className="ln">{start + i}</span>
          {l}
        </div>
      ))}
    </pre>
  );
}
```

```tsx
import type { Zone } from '@mapskill/core/client';
import { useCallback, useEffect, useState } from 'react';
import { takeToken } from './api';
import { ActivityBar } from './components/ActivityBar';
import { Header } from './components/Header';
import { MapView } from './components/MapView';
import { SidePanel } from './components/SidePanel';
import { useMapConnection } from './connection';
import { pickLang, STRINGS, type Lang } from './i18n';
import { useSlots } from './slots';

const LANG_KEY = 'mapskill-lang';
const ERROR_MS = 6000;

const { token, cleanUrl } = takeToken(location, sessionStorage);
if (cleanUrl) history.replaceState(null, '', cleanUrl);

function savedLang(): string | null {
  try {
    return localStorage.getItem(LANG_KEY);
  } catch {
    return null;
  }
}

function MapApp({ token }: { token: string }) {
  const { state, api } = useMapConnection(token);
  const slots = useSlots(state.graph, api);
  const [lang, setLang] = useState<Lang>(() => pickLang(navigator.language, savedLang()));
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const [showAllEdges, setShowAllEdges] = useState(false);
  const [collapsed, setCollapsed] = useState<ReadonlySet<Zone>>(() => new Set<Zone>(['tests']));
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    document.documentElement.lang = lang;
  }, [lang]);
  useEffect(() => {
    if (!error) return;
    const timer = setTimeout(() => setError(null), ERROR_MS);
    return () => clearTimeout(timer);
  }, [error]);

  const toggleLang = (): void => {
    const next: Lang = lang === 'sv' ? 'en' : 'sv';
    setLang(next);
    try {
      localStorage.setItem(LANG_KEY, next);
    } catch {
      // private window: the choice lasts this visit only
    }
  };
  const toggleZone = useCallback((zone: Zone) => {
    setCollapsed((prev) => {
      const next = new Set(prev);
      if (next.has(zone)) next.delete(zone);
      else next.add(zone);
      return next;
    });
  }, []);
  const select = useCallback((id: string | null) => setSelectedId(id), []);

  const graph = state.graph;
  const node = graph && selectedId ? graph.nodes.find((n) => n.id === selectedId) ?? null : null;

  return (
    <div className="app">
      <Header graph={graph} status={state.status} lang={lang} showAllEdges={showAllEdges} onShowAllEdges={setShowAllEdges} onToggleLang={toggleLang} />
      <div className={`main${node ? '' : ' no-panel'}`}>
        <div className="map">
          {graph ? (
            <MapView graph={graph} state={state} slots={slots} selectedId={selectedId} onSelect={select} showAllEdges={showAllEdges} collapsed={collapsed} onToggleZone={toggleZone} lang={lang} />
          ) : (
            <p className="muted center">{STRINGS[lang].connecting}</p>
          )}
        </div>
        {graph && node && (
          <div className="panel-wrap">
            {error && (
              <p className="error" role="alert">
                {error}
              </p>
            )}
            <SidePanel graph={graph} node={node} locked={!!node.file && state.lockedFiles.includes(node.file)} lang={lang} api={api} onSelect={select} onError={setError} />
          </div>
        )}
      </div>
      <ActivityBar activity={state.activity} requests={state.requests} graph={graph} lang={lang} api={api} />
    </div>
  );
}

export function App() {
  if (!token) {
    return (
      <main className="center">
        <p>{STRINGS.en.noToken}</p>
        <p lang="sv">{STRINGS.sv.noToken}</p>
      </main>
    );
  }
  return <MapApp token={token} />;
}
```

```ts
// packages/ui/e2e/global-setup.ts
import { spawnSync } from 'node:child_process';
import fs from 'node:fs';
import { createRequire } from 'node:module';
import os from 'node:os';
import path from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';

const here = path.dirname(fileURLToPath(import.meta.url));
export const repo = path.resolve(here, '../../..');

/** Runs the CLI from source the way the daemon spawner does in development (node + tsx loader + bin.ts). */
export function cli(args: string[], env: NodeJS.ProcessEnv = {}): { status: number | null; stdout: string; stderr: string } {
  const loader = createRequire(path.join(repo, 'packages/cli/package.json')).resolve('tsx');
  const r = spawnSync(process.execPath, ['--import', pathToFileURL(loader).href, path.join(repo, 'packages/cli/src/bin.ts'), ...args], {
    encoding: 'utf8',
    env: { ...process.env, ...env },
    timeout: 60_000,
  });
  return { status: r.status, stdout: r.stdout, stderr: r.stderr };
}

export default function globalSetup(): void {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), 'mapskill-pw-'));
  fs.cpSync(path.join(repo, 'fixtures', 'clean-app'), root, { recursive: true, filter: (src) => !src.split(path.sep).includes('.mapskill') });
  const r = cli(['open', root, '--no-browser'], { MAPSKILL_UI_DIR: path.join(repo, 'packages', 'ui', 'dist') });
  const url = /Mapskill map: (\S+)/.exec(r.stdout)?.[1];
  if (r.status !== 0 || !url) throw new Error(`could not start Mapskill: ${r.stdout} ${r.stderr}`);
  process.env.MAPSKILL_E2E_URL = url;
  process.env.MAPSKILL_E2E_ROOT = root;
}
```

```ts
// packages/ui/e2e/smoke.spec.ts
import fs from 'node:fs';
import path from 'node:path';
import { expect, test, type Page } from '@playwright/test';

const url = (): string => process.env.MAPSKILL_E2E_URL!;
const root = (): string => process.env.MAPSKILL_E2E_ROOT!;
const token = (): string => new URL(url()).searchParams.get('t')!;
const api = async <T>(p: string): Promise<T> => {
  const res = await fetch(new URL(p, url()), { headers: { 'x-mapskill-token': token() } });
  return (await res.json()) as T;
};
type Graph = { nodes: { id: string; label: string; file?: string; zone: string }[] };

async function open(page: Page): Promise<Graph> {
  await page.goto(url());
  const graph = await api<Graph>('/api/graph');
  await expect(page.locator('[data-node-id]').first()).toBeVisible();
  return graph;
}

async function boxes(page: Page): Promise<Record<string, { x: number; y: number }>> {
  const out: Record<string, { x: number; y: number }> = {};
  for (const el of await page.locator('[data-node-id]').all()) {
    const id = (await el.getAttribute('data-node-id'))!;
    const b = (await el.boundingBox())!;
    out[id] = { x: Math.round(b.x), y: Math.round(b.y) };
  }
  return out;
}

test('renders clean-app with every part', async ({ page }) => {
  const graph = await open(page);
  const shown = graph.nodes.filter((n) => n.zone !== 'tests');
  await expect(page.locator('[data-node-id]')).toHaveCount(shown.length);
  await expect(page.getByRole('button', { name: /^Pages/ })).toBeVisible();
  expect(new URL(page.url()).searchParams.get('t')).toBeNull();
});

test('click opens the panel', async ({ page }) => {
  const graph = await open(page);
  const first = graph.nodes.find((n) => n.zone !== 'tests')!;
  await page.locator(`[data-node-id="${first.id}"]`).click();
  await expect(page.locator('aside.panel h2')).toContainText(first.label);
});

test('keyboard: Tab to a part, Enter opens the panel, Escape closes it', async ({ page }) => {
  await open(page);
  for (let i = 0; i < 60; i++) {
    await page.keyboard.press('Tab');
    if (await page.evaluate(() => document.activeElement?.hasAttribute('data-node-id'))) break;

  await page.keyboard.press('Enter');
  await expect(page.locator('aside.panel')).toBeVisible();
  await page.locator('aside.panel button').first().focus();
  await page.keyboard.press('Escape');
  await expect(page.locator('aside.panel')).toHaveCount(0);
```
