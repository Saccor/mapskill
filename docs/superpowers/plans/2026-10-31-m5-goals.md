# Mapskill M5: mål och spöknoder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Användaren väljer ett mål i kartan, till exempel "SaaS med inloggning och betalning". Kartan visar då vad som redan finns, och det som saknas syns som streckade spöknoder i rätt zon.

- **Bygg:** en Bygg-knapp på varje spöknod lägger en färdig förfrågan till Claude i kön. Kön skickas med nästa gång användaren skriver till Claude.
- **Claude:** får samma bild genom MCP-verktyget `goal_gaps`.

**Architecture:** Målen är data i `@mapskill/core`: fyra inbyggda mallar med kontroller.

- **Kontrollerna:** `fileExists`, `anyNode` med filter, `noFindings`, `all` och `any`.
- **Utvärdering:** en ren funktion i core utvärderar en mall mot den publika grafen och en `fileExists`-funktion som daemonen ger, och returnerar `GoalStatus`.
- **Daemonen:** sparar valt mål i `.mapskill/goal.yaml` och räknar om status efter varje ändring. Ny status pushas över WebSocket (`{ type: 'goal' }`).
- **Kartvyn:** lägger in saknade punkter som planerade rutor (`planned: true`) i en visningsgraf. Platsplacering, tangentbord och sidopanel fungerar därför som för vanliga rutor.

**Tech Stack:** Node 22, pnpm-arbetsyta, TypeScript `~5.9.3`, Vitest, React 19, React Flow 12, Playwright med Edge. Inga nya beroenden.

Spec: [../specs/2026-10-30-mapskill-mvp-design.md](../specs/2026-10-30-mapskill-mvp-design.md) (1 mål 6, 4.3 Mål och mallar, 4.3 Förfrågningar och lås, 4.3 MCP-server, 5.4, 8 fixture 4). Färdplan: [2026-10-30-mapskill-roadmap.md](2026-10-30-mapskill-roadmap.md). Föregående plan: [2026-10-31-m4-map-view.md](2026-10-31-m4-map-view.md).

## Global Constraints

- Node `>=22.12`. pnpm `>=10`. `typescript` låst till `~5.9.3`. Inga nya beroenden någonstans.
- `@mapskill/core` har inga sidoeffekter utöver filläsning. Målutvärderingen i core läser inte disken själv: den får en `fileExists(rel)`-funktion av anroparen.
- Kartvyn importerar bara `@mapskill/core/client`. Allt den behöver om mål, alltså typer och texter, exporteras därifrån.
- Ingen fil under `packages/cli/src/hooks/` får göra en körtidsimport av `@mapskill/core`.
- Utvärderingen är helt deterministisk. Samma graf och samma filer ger samma status, och punkterna kommer i mallens ordning.
- Mapskill skriver bara i `.mapskill/`. Valt mål sparas i `.mapskill/goal.yaml` med exakt innehållet `goal: <mål-id>\n`. Inget mål betyder att filen tas bort. `.gitignore` släpper redan igenom filen (`!.mapskill/goal.yaml`, M2), så användaren kan checka in den.
- `fileExists` i daemonen godtar bara projektrelativa sökvägar utan `..`, utan absoluta sökvägar och utan `.mapskill/`.
- All text som visas för användaren finns på engelska och svenska. Mallarnas titlar och förklaringar är `{ en, sv }`.
- Text till Claude (förfrågningar) skrivs på användarens valda språk. MCP-verktygets text är på engelska.
- Säkerhetsreglerna från M2–M4 gäller för de nya vägarna: token, Host-kontroll, kroppar högst 1 MB.
- Spöknoder får aldrig blandas ihop med riktiga rutor:
  - id `ghost:<punkt-id>`
  - `planned: true`
  - streckad ram och `+`-ikon
  - ordet "Saknas" eller "Missing" i skärmläsarens etikett
  - aldrig Lås-knapp, kod eller fynd
- Tillgänglighet som i M4: varje spöknod nås med Tab och öppnas med Enter, och färg är aldrig enda signalen.
- Modulsystem: ESM, importer utan filändelse i källkoden, `moduleResolution: "Bundler"`.
- Varje commit-meddelande avslutas med raden `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Lägg aldrig till `.superpowers/`, `plugin/dist/` eller `packages/ui/dist/` i git.

## Avvikelser från specen (medvetna)

| Spec | Den här planen | Varför |
|---|---|---|
| Inbyggda mallar som YAML-filer i `goals/*.yaml` | Mallarna är data i TypeScript (`packages/core/src/goals/builtin.ts`) med samma fält som specens YAML-exempel | En YAML-tolk skulle bli ett nytt beroende i core. Med bara inbyggda mallar ger YAML ingen nytta än. Egna mallar från användaren kan läsas som YAML senare med samma typer |
| `.mapskill/goal.yaml` beskrivs inte närmare | Filen innehåller en rad: `goal: <id>`. Core tolkar den med en egen liten funktion | En rad behöver ingen YAML-tolk |
| `PUT /api/goal` | `POST /api/goal { goalId: string \| null }` | Klienterna i CLI:t och daemonen använder GET och POST. Samma val som för `POST /api/similar` och `POST /api/layout` |
| `talksTo` och `touchesTable` i kontrollerna | Gäller rutan själv eller det den använder i upp till tre steg (`uses`-kanter) | En betal-rutt anropar ofta Stripe via en hjälpfil i `lib/`. Bara direkta kanter skulle ge falska spöknoder |
| Spöknoder för varje ej uppfylld punkt | Bara för punkter som har `nodeType`. Punkter som `noFindings` visas i målpanelen men blir ingen ruta | "Inga hårdkodade nycklar" är ingen sak att lägga till på kartan |
| Bygg-texten "Återanvänd befintliga <relevanta noder>" | Relevanta rutor är upp till tre befintliga rutor av samma typ, i samma zon | Specen säger inte hur de väljs. Samma typ i samma zon är det enklaste deterministiska valet |

Miljö för den som kör planen: arbeta på grenen `m5-goals`, skapad från `master`.

```ts
// goals/types.ts
export interface NodeFilter {
  type?: NodeType;
  /** Regex (case-insensitive) on the node's route. */
  routeMatches?: string;
  /** Service id ('stripe', 'supabase', …): the node or something it uses (up to 3 steps) talks to it. */
  talksTo?: string;
  /** Regex (case-insensitive) on a table name the node or something it uses (up to 3 steps) reads or writes. */
  touchesTable?: string;
  /** Regex (case-insensitive) on the node's label. */
  nameMatches?: string;
}
export type GoalCheck =
  | { fileExists: string }
  | { anyNode: NodeFilter }
  | { noFindings: FindingKind }
  | { all: GoalCheck[] }
  | { any: GoalCheck[] };
export interface GoalItem { id: string; title: Text; why: Text; nodeType?: NodeType; check: GoalCheck; suggest?: { path: string } }
export interface GoalTemplate { id: string; title: Text; description: Text; extends?: string; items: GoalItem[] }
// protocol.ts
export interface GoalItemStatus {
  id: string; title: Text; why: Text; done: boolean;
  nodeType?: NodeType; zone?: Zone; suggestPath?: string;
  /** Up to 5 nodes that satisfied an anyNode check. */
  matchedNodeIds: string[];
}
export interface GoalStatus { goalId: string; title: Text; items: GoalItemStatus[]; done: number; total: number }
export interface GoalSummary { id: string; title: Text; description: Text }
export interface GoalAnswer { goals: GoalSummary[]; status: GoalStatus | null }
export type RequestKind = 'explain' | 'fix' | 'custom' | 'build';
// ServerMessage gets: | { type: 'goal'; status: GoalStatus | null }
// build-model.ts
export const ZONE_OF_TYPE: Record<NodeType, Zone>; // the existing ZONE map, exported under this name
// goals/builtin.ts
export const BUILTIN_GOALS: GoalTemplate[];         // landing-page, webapp-auth, saas-auth-payments, crud-app
// goals/evaluate.ts
export function goalSummaries(templates?: GoalTemplate[]): GoalSummary[];
export function findGoal(id: string, templates?: GoalTemplate[]): GoalTemplate | null;            // with extends resolved
export function evaluateGoal(template: GoalTemplate, graph: PublicGraph, fileExists: (rel: string) => boolean): GoalStatus;
// goals/goal-file.ts
export function parseGoalFile(text: string): string | null;   // 'goal: <id>' -> id; anything else -> null
export function formatGoalFile(id: string): string;           // 'goal: <id>\n'
```

`@mapskill/core/client` exporterar dessutom `GoalItemStatus`, `GoalStatus`, `GoalSummary`, `GoalAnswer` (de ligger i `protocol.ts` och följer med) och `ZONE_OF_TYPE`. Flytta `ZONE` till en egen liten fil `packages/core/src/model/zones.ts`, så att `client.ts` kan exportera den utan att dra in `build-model.ts` (som importerar `node:path`). `build-model.ts` importerar den därifrån.

Regler för utvärderingen:
- **Mallar som bygger på andra:** `findGoal` löser upp `extends` rekursivt. Föräldrarnas punkter kommer först, och en egen punkt med samma id ersätter förälderns på dess plats. En cykel ger ett fel (`Error('goal extends cycle: …')`).
- **`anyNode`:** sann om minst en ruta som inte är planerad (`!planned`) uppfyller alla angivna filter.
  - `type` jämförs exakt.
  - `routeMatches` matchar mot `node.route` (saknas rutten blir det falskt).
  - `nameMatches` matchar mot `node.label`.
  - `talksTo: 'x'` betyder att rutan själv eller någon ruta den når via `uses`-kanter i högst 3 steg har en `talks-to`-kant till `service:x`.
  - `touchesTable: 'r'` betyder samma sak för en `reads`- eller `writes`-kant till `table:<namn>` där namnet matchar `r`.
  - Alla reguljära uttryck är skiftlägesokänsliga.
  - Ett ogiltigt uttryck gör filtret falskt. Utvärderingen kastar aldrig fel.
- **`fileExists`:** frågar anroparens funktion.
- **`noFindings`:** sann om grafen saknar fynd av den typen.
- **`all` och `any`:** som vanligt logiskt och respektive eller. En tom `all` är sann och en tom `any` är falsk.
- **`matchedNodeIds`:** id:n för de rutor som uppfyllde den första `anyNode`-kontroll som blev sann i punkten, högst 5, sorterade.
- **Status:** `zone` är `ZONE_OF_TYPE[nodeType]` när `nodeType` finns. `done` är antalet uppfyllda punkter och `total` är antalet punkter.

De fyra inbyggda målen, i den här ordningen (titlar och förklaringar på enkel svenska och engelska):

1. `landing-page`: Landningssida / Landing page
2. `webapp-auth`: Webbapp med inloggning / Web app with login
3. `saas-auth-payments` (`extends: webapp-auth`): SaaS med inloggning och betalning / SaaS with login and payments
4. `crud-app`: Intern CRUD-app / Internal CRUD app

```ts
// packages/core/src/goals/goals.test.ts
import fs from 'node:fs';
import path from 'node:path';
import { describe, expect, it } from 'vitest';
import { toPublicGraph, type PublicGraph } from '../graph/delta';
import { scanProject } from '../graph/scan';
import { fixture } from '../test-helpers';
import { BUILTIN_GOALS } from './builtin';
import { evaluateGoal, findGoal, goalSummaries } from './evaluate';
import { formatGoalFile, parseGoalFile } from './goal-file';
import type { GoalTemplate } from './types';

const onDisk = (root: string) => (rel: string) => fs.existsSync(path.join(root, rel));
const status = (fixtureName: string, goalId: string) => {
  const root = fixture(fixtureName);
  return evaluateGoal(findGoal(goalId)!, toPublicGraph(scanProject(root)), onDisk(root));
};

const g = (over: Partial<PublicGraph>): PublicGraph => ({
  root: '/p', framework: 'nextjs', nodes: [], edges: [], findings: [], health: {}, fileCount: 0, unreadableFiles: [], ...over,
});

describe('built-in goals', () => {
  it('has four goals with unique item ids and texts in both languages', () => {
    expect(goalSummaries().map((s) => s.id)).toEqual(['landing-page', 'webapp-auth', 'saas-auth-payments', 'crud-app']);
    for (const t of BUILTIN_GOALS) {
      const resolved = findGoal(t.id)!;
      const ids = resolved.items.map((i) => i.id);
      expect(new Set(ids).size).toBe(ids.length);
      for (const i of resolved.items) {
        expect(i.title.en && i.title.sv && i.why.en && i.why.sv).toBeTruthy();
      }
    }
  });

  it('half-saas misses exactly the payment parts of the SaaS goal', () => {
    const s = status('half-saas', 'saas-auth-payments');
    expect(s.items.filter((i) => !i.done).map((i) => i.id)).toEqual(['pricing-page', 'checkout', 'webhook', 'subscriptions-table']);
    expect(s.done).toBe(s.total - 4);
    const checkout = s.items.find((i) => i.id === 'checkout')!;
    expect(checkout).toMatchObject({ nodeType: 'api-route', zone: 'server', suggestPath: 'app/api/checkout/route.ts' });
  });

  it('half-saas meets the whole web-app-with-login goal', () => {
    const s = status('half-saas', 'webapp-auth');
    expect(s.items.filter((i) => !i.done).map((i) => i.id)).toEqual([]);
    expect(s.items.find((i) => i.id === 'login-page')!.matchedNodeIds).toEqual(['page:app/login/page.tsx']);
  });

  it('clean-app has a home page and a layout but no login', () => {
    const s = status('clean-app', 'webapp-auth');
    const done = new Set(s.items.filter((i) => i.done).map((i) => i.id));
    expect(done.has('home-page')).toBe(true);
    expect(done.has('root-layout')).toBe(true);
    expect(done.has('login-page')).toBe(false);
  });
});

describe('evaluateGoal checks', () => {
  const t = (items: GoalTemplate['items']): GoalTemplate => ({ id: 't', title: { en: 't', sv: 't' }, description: { en: '', sv: '' }, items });
  const item = (check: GoalTemplate['items'][number]['check']) => ({ id: 'i', title: { en: 'i', sv: 'i' }, why: { en: 'w', sv: 'w' }, check });

  it('follows uses edges up to three steps for talksTo and touchesTable', () => {
    const graph = g({
      nodes: [
        { id: 'api-route:a', type: 'api-route', zone: 'server', label: 'POST /api/checkout', route: '/api/checkout', file: 'a' },
        { id: 'helper:b#b', type: 'helper', zone: 'shared', label: 'b', file: 'b' },
        { id: 'helper:c#c', type: 'helper', zone: 'shared', label: 'c', file: 'c' },
        { id: 'service:stripe', type: 'service', zone: 'outside', label: 'Stripe' },
        { id: 'table:subscriptions', type: 'table', zone: 'data', label: 'subscriptions' },
      ],
      edges: [
        { id: 'e1', from: 'api-route:a', to: 'helper:b#b', kind: 'uses' },
        { id: 'e2', from: 'helper:b#b', to: 'helper:c#c', kind: 'uses' },
        { id: 'e3', from: 'helper:c#c', to: 'service:stripe', kind: 'talks-to' },
        { id: 'e4', from: 'helper:c#c', to: 'table:subscriptions', kind: 'writes' },
      ],
    });
    const yes = evaluateGoal(t([item({ anyNode: { type: 'api-route', talksTo: 'stripe', touchesTable: '^subscriptions$' } })]), graph, () => false);
    expect(yes.items[0]).toMatchObject({ done: true, matchedNodeIds: ['api-route:a'] });
    const far = g({ ...graph, edges: [{ id: 'x', from: 'api-route:a', to: 'helper:b#b', kind: 'uses' }] });
    expect(evaluateGoal(t([item({ anyNode: { type: 'api-route', talksTo: 'stripe' } })]), far, () => false).items[0].done).toBe(false);
  });

  it('combines checks, reads files through the callback and never throws on a bad regex', () => {
    const graph = g({ nodes: [{ id: 'page:p', type: 'page', zone: 'pages', label: '/Login', route: '/Login', file: 'p' }] });
    const s = evaluateGoal(
      t([
        { ...item({ any: [{ fileExists: 'nope' }, { anyNode: { routeMatches: '^/login$' } }] }), id: 'a' },
        { ...item({ all: [{ fileExists: '.env.example' }, { noFindings: 'hardcoded-secret' }] }), id: 'b' },
        { ...item({ anyNode: { nameMatches: '(' } }), id: 'c' },
        { ...item({ all: [] }), id: 'd' },
        { ...item({ any: [] }), id: 'e' },
      ]),
      graph,
      (rel) => rel === '.env.example',
    );
    expect(s.items.map((i) => [i.id, i.done])).toEqual([['a', true], ['b', true], ['c', false], ['d', true], ['e', false]]);
    expect(s.done).toBe(3);
  });

  it('ignores planned nodes', () => {
    const graph = g({ nodes: [{ id: 'ghost:x', type: 'page', zone: 'pages', label: '/login', route: '/login', planned: true }] });
    expect(evaluateGoal(t([item({ anyNode: { type: 'page' } })]), graph, () => false).items[0].done).toBe(false);
  });
```

```ts
const ID = /^[a-z0-9-]+$/;

/** The goal id in .mapskill/goal.yaml ('goal: <id>'), or null when the file says nothing usable. */
export function parseGoalFile(text: string): string | null {
  for (const line of text.split(/\r?\n/)) {
    const m = /^\s*goal\s*:\s*(\S+)\s*$/.exec(line);
    if (m) return ID.test(m[1]) ? m[1] : null;
  }
  return null;
}

export function formatGoalFile(id: string): string {
  return `goal: ${id}\n`;
```

```ts
// packages/core/src/goals/evaluate.ts
import type { PublicGraph } from '../graph/delta';
import type { GoalItemStatus, GoalStatus, GoalSummary } from '../model/protocol';
import type { MapNode } from '../model/types';
import { ZONE_OF_TYPE } from '../model/zones';
import { BUILTIN_GOALS } from './builtin';
import type { GoalCheck, GoalItem, GoalTemplate, NodeFilter } from './types';

const MAX_STEPS = 3;
const MAX_MATCHES = 5;

export function goalSummaries(templates: GoalTemplate[] = BUILTIN_GOALS): GoalSummary[] {
  return templates.map((t) => ({ id: t.id, title: t.title, description: t.description }));
}

/** The template with its `extends` chain resolved: parent items first, a child item with the same id replaces it in place. */
export function findGoal(id: string, templates: GoalTemplate[] = BUILTIN_GOALS, seen: string[] = []): GoalTemplate | null {
  if (seen.includes(id)) throw new Error(`goal extends cycle: ${[...seen, id].join(' -> ')}`);
  const t = templates.find((x) => x.id === id);
  if (!t) return null;
  if (!t.extends) return t;
  const parent = findGoal(t.extends, templates, [...seen, id]);
  if (!parent) return t;
  const items: GoalItem[] = parent.items.map((p) => t.items.find((c) => c.id === p.id) ?? p);
  for (const c of t.items) if (!items.some((i) => i.id === c.id)) items.push(c);
  return { ...t, items };
}

function regex(source: string): RegExp | null {
  try {
    return new RegExp(source, 'i');
  } catch {
    return null;
  }
}

/** The node plus every node it reaches over `uses` edges in at most MAX_STEPS steps. */
function reach(graph: PublicGraph, start: string): Set<string> {
  const out = new Set([start]);
  let frontier = [start];
  for (let step = 0; step < MAX_STEPS && frontier.length > 0; step++) {
    const next: string[] = [];
    for (const id of frontier) {
      for (const e of graph.edges) {
        if (e.from === id && e.kind === 'uses' && !out.has(e.to)) {
          out.add(e.to);
          next.push(e.to);
        }
      }
    }
    frontier = next;
  }
  return out;
}

function matches(graph: PublicGraph, n: MapNode, f: NodeFilter): boolean {
  if (n.planned) return false;
  if (f.type && n.type !== f.type) return false;
  if (f.routeMatches !== undefined) {
    const r = regex(f.routeMatches);
    if (!r || n.route === undefined || !r.test(n.route)) return false;
  }
  if (f.nameMatches !== undefined) {
    const r = regex(f.nameMatches);
    if (!r || !r.test(n.label)) return false;
  }
  if (f.talksTo !== undefined || f.touchesTable !== undefined) {
    const nodes = reach(graph, n.id);
    const from = graph.edges.filter((e) => nodes.has(e.from));
    if (f.talksTo !== undefined && !from.some((e) => e.kind === 'talks-to' && e.to === `service:${f.talksTo}`)) return false;
    if (f.touchesTable !== undefined) {
      const r = regex(f.touchesTable);
      const hit = (e: { kind: string; to: string }) =>
        (e.kind === 'reads' || e.kind === 'writes') && e.to.startsWith('table:') && r !== null && r.test(e.to.slice('table:'.length));
      if (!from.some(hit)) return false;
    }
  }
  return true;
}

/** Result of one check, and the nodes of the first anyNode that was true. */
function run(graph: PublicGraph, c: GoalCheck, fileExists: (rel: string) => boolean): { ok: boolean; nodes: string[] } {
  if ('fileExists' in c) return { ok: fileExists(c.fileExists), nodes: [] };
  if ('noFindings' in c) return { ok: !graph.findings.some((f) => f.kind === c.noFindings), nodes: [] };
  if ('anyNode' in c) {
    const hits = graph.nodes.filter((n) => matches(graph, n, c.anyNode)).map((n) => n.id).sort();
    return { ok: hits.length > 0, nodes: hits.slice(0, MAX_MATCHES) };
  }
  if ('all' in c) {
    let nodes: string[] = [];
    for (const sub of c.all) {
      const r = run(graph, sub, fileExists);
      if (!r.ok) return { ok: false, nodes: [] };
      if (nodes.length === 0) nodes = r.nodes;
    }
    return { ok: true, nodes };
  }
  for (const sub of c.any) {
    const r = run(graph, sub, fileExists);
    if (r.ok) return r;
  }
  return { ok: false, nodes: [] };
}

export function evaluateGoal(template: GoalTemplate, graph: PublicGraph, fileExists: (rel: string) => boolean): GoalStatus {
  const items: GoalItemStatus[] = template.items.map((i) => {
    const r = run(graph, i.check, fileExists);
    return {
      id: i.id,
      title: i.title,
      why: i.why,
      done: r.ok,
      ...(i.nodeType ? { nodeType: i.nodeType, zone: ZONE_OF_TYPE[i.nodeType] } : {}),
      ...(i.suggest ? { suggestPath: i.suggest.path } : {}),
      matchedNodeIds: r.ok ? r.nodes : [],
    };
  });
  return { goalId: template.id, title: template.title, items, done: items.filter((i) => i.done).length, total: items.length };
}
```

```ts
export function formatGoalGaps(status: GoalStatus | null): string {
  if (!status) return 'No goal is chosen in the Mapskill map. The user can pick one at the top of the map.';
  const missing = status.items.filter((i) => !i.done);
  const lines = [`Goal: ${status.title.en} (${status.done}/${status.total} done).`];
  if (missing.length === 0) lines.push('Missing: nothing.');
  else {
    lines.push('Missing:');
```

```ts
// packages/ui/src/goals.ts
import type { GoalItemStatus, GoalStatus, MapNode, PublicGraph } from '@mapskill/core/client';
import { t, type Lang } from './i18n';

export const GHOST_PREFIX = 'ghost:';
const MAX_REUSE = 3;

export function ghostNodes(status: GoalStatus | null, lang: Lang): MapNode[] {
  if (!status) return [];
  return status.items
    .filter((i) => !i.done && i.nodeType && i.zone)
    .map((i) => ({ id: `${GHOST_PREFIX}${i.id}`, type: i.nodeType!, zone: i.zone!, label: i.title[lang], planned: true }));
}

/** The graph the map shows: real parts plus the goal's missing parts as planned ghosts. */
export function withGhosts(graph: PublicGraph, status: GoalStatus | null, lang: Lang): PublicGraph {
  const ghosts = ghostNodes(status, lang);
  return ghosts.length === 0 ? graph : { ...graph, nodes: [...graph.nodes, ...ghosts] };
}

export function ghostItem(status: GoalStatus | null, nodeId: string): GoalItemStatus | null {
  if (!status || !nodeId.startsWith(GHOST_PREFIX)) return null;
  return status.items.find((i) => i.id === nodeId.slice(GHOST_PREFIX.length)) ?? null;
}

export function goalLine(status: GoalStatus, lang: Lang): string {
  return t(lang, 'goalLine', { title: status.title[lang], done: status.done, total: status.total });
}

export function buildText(item: GoalItemStatus, graph: PublicGraph, lang: Lang): string {
  const parts = [t(lang, 'buildSentence', { title: item.title[lang], why: item.why[lang].replace(/\.\s*$/, '') })];
  if (item.suggestPath) parts.push(t(lang, 'placeSentence', { path: item.suggestPath }));
  const reuse = graph.nodes
    .filter((n) => !n.planned && n.type === item.nodeType && n.zone === item.zone)
    .map((n) => n.label)
    .sort((a, b) => (a < b ? -1 : a > b ? 1 : 0))
    .slice(0, MAX_REUSE);
  if (reuse.length > 0) parts.push(t(lang, 'reuseSentence', { list: reuse.join(', ') }));
  return parts.join(' ');
}
```
