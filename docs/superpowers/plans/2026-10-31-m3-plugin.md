# Mapskill M3: Claude Code-plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gör skyddsräcket verkligt i Claude Code. Ett plugin startar daemonen från M2 när sessionen börjar. Claude stoppas från att ändra filer som användaren låst. Innan Claude avslutar ett varv får den de nya säkra fynden i filer den själv ändrat, högst en gång per varv. Claude får också fyra MCP-verktyg för att hitta befintlig kod och förstå kartan, och en skill som säger åt den att använda dem.

**Architecture:** Allt körs genom CLI:t `mapskill`. Pluginet (`plugin/`) innehåller bara konfiguration (`hooks.json`, `.mcp.json`, `plugin.json`), en skill och en paketerad fil `plugin/dist/mapskill.mjs`. Varje hook är `node mapskill.mjs hook <event>`: läser JSON från stdin, frågar daemonen över HTTP och svarar Claude Code med exitkod och stdout/stderr. Låskontrollen läser `.mapskill/locks.json` direkt från disk och fungerar utan daemon. Hooks laddar aldrig `@mapskill/core` (som drar in TypeScript-kompilatorn), så de startar snabbt. MCP-servern (`mapskill mcp`) är ett tunt lager över nya HTTP-vägar i daemonen. Svaren byggs av rena funktioner i core: översikt, liknande funktioner och nodinfo.

**Tech Stack:** Node 22, pnpm-arbetsyta, TypeScript `~5.9.3`, Vitest, tsx. Nya beroenden: `@modelcontextprotocol/sdk` `^1.32.2` och `zod` `^4.1.0` i `mapskill` (ren JavaScript), `esbuild` `^0.28.2` som dev-beroende i arbetsytans rot (paketerar pluginet).

Spec: [../specs/2026-10-30-mapskill-mvp-design.md](../specs/2026-10-30-mapskill-mvp-design.md). Färdplan: [2026-10-30-mapskill-roadmap.md](2026-10-30-mapskill-roadmap.md). Föregående plan: [2026-10-30-m2-daemon.md](2026-10-30-m2-daemon.md).

## Global Constraints

- Node `>=22`. pnpm `>=10`. `typescript` låst till `~5.9.3`.
- Inga native-beroenden i `@mapskill/core` eller `mapskill`. Nya körberoenden bara `@modelcontextprotocol/sdk` `^1.32.2` och `zod` `^4.1.0` i `mapskill`. `esbuild` `^0.28.2` endast som dev-beroende i roten.
- Alla sökvägar i datamodellen och i HTTP-svar är relativa till projektroten och använder `/` även på Windows.
- Ingen nätverkstrafik utöver `127.0.0.1`, ingen LLM, ingen telemetri. Mapskill skriver bara i `.mapskill/` och, en gång, i en befintlig `.gitignore`.
- `@mapskill/core` har inga sidoeffekter utöver filläsning.
- Ingen fil under `packages/cli/src/hooks/`, och inte `packages/cli/src/locks.ts` eller `packages/cli/src/project-path.ts`, får göra en körtidsimport av `@mapskill/core`. Typimporter (`import type`) är tillåtna.
- Hooks är fail-open: varje fel eller tidsgräns släpper igenom Claude (exitkod 0 utan utdata) och skriver en rad i `.mapskill/log.txt`. Det enda undantaget är låskontrollen, som blockerar när en fil är låst eller när `locks.json` inte går att läsa.
- Hooks som pratar med daemonen gör ingenting i en mapp utan `package.json` eller `tsconfig.json`, och skapar då inte heller `.mapskill/`.
- Blockering i PreToolUse: exitkod 2 med skälet på stderr. Blockering i Stop: exitkod 0 med `{"decision":"block","reason":"…"}` på stdout, aldrig när `stop_hook_active` är sant, och högst en gång per varv (daemonen håller räkningen).
- Stop-hooken rapporterar bara fynd med säkerhet `certain` som är nya sedan varvets början och rör filer Claude ändrat i varvet. Högst 5 fynd i texten.
- Tidsgränser i `hooks.json` (sekunder): SessionStart 10, UserPromptSubmit 5, PreToolUse 5, PostToolUse 5, Stop 15. Hookens egen tidsgräns inuti processen ligger under dessa: 9, 4, 4, 4 och 12 sekunder.
- Text till Claude (hooks, MCP, skill) är på engelska. Skillen säger åt Claude att svara på svenska när användaren skriver svenska. CLI-meddelanden är på engelska (beslut B6).
- Daemonens säkerhetsregler från M2 gäller oförändrat för de nya vägarna: token i `x-mapskill-token`, Host-kontroll, kroppar högst 1 MB.
- `DAEMON_VERSION` blir `'0.2.0'`. En daemon med annan version byts ut automatiskt.
- Modulsystem: ESM (`"type": "module"`), importer utan filändelse i källkoden, `moduleResolution: "Bundler"`. Importer från MCP SDK använder dess egna sökvägar med `.js` (till exempel `@modelcontextprotocol/sdk/server/mcp.js`).

```ts
// packages/cli/src/project-path.ts
import fs from 'node:fs';
import path from 'node:path';

/** The on-disk spelling of `p` (letter case, junctions and symlinks resolved), or null when it does not exist. */
export function realPath(p: string): string | null {
  try {
    return fs.realpathSync.native(p);
  } catch {
    return null;
  }
}

/** Absolute project root in its on-disk spelling (or as given when the folder does not exist). */
export function canonicalRoot(dir: string): string {
  const abs = path.resolve(dir);
  return realPath(abs) ?? abs;
}

/**
 * Project-relative path with '/' separators, or null when `file` lies outside the project (or is the root itself).
 * `root` must be canonical. An existing file is resolved to its on-disk spelling first, so a hook path with other
 * letter case on Windows still maps to the path the graph uses. A deleted file maps as given.
 */
export function toProjectRel(root: string, file: string): string | null {
  const abs = path.resolve(root, file);
  const rel = path.relative(root, realPath(abs) ?? abs).split(path.sep).join('/');
  if (rel === '' || rel === '..' || rel.startsWith('../') || path.isAbsolute(rel)) return null;
  return rel;
}

/** The nearest folder at or above `start` that has a package.json, or `start` itself when none has. Canonical. */
export function findProjectRoot(start: string): string {
  const first = canonicalRoot(start);
  for (let dir = first; ; ) {
    if (fs.existsSync(path.join(dir, 'package.json'))) return dir;
    const parent = path.dirname(dir);
    if (parent === dir) return first;
    dir = parent;
  }
}
```

```ts
// packages/cli/src/locks.ts
import fs from 'node:fs';
import path from 'node:path';
import { ensureMapskillDir, mapskillPath, writeJsonAtomic } from './daemon/paths';
import { toProjectRel } from './project-path';

// This module must not import @mapskill/core: the PreToolUse hook loads it on every edit.

export interface Lock {
  /** Project-relative file ('lib/pay.ts') or folder ending in '/' ('lib/payments/'). */
  path: string;
  /** What the user locked, in their words ('Betalning'). Shown to Claude when an edit is refused. */
  label?: string;
  lockedAt: number;
}

export type LocksResult = { ok: true; locks: Lock[] } | { ok: false; error: string };

export function locksFile(root: string): string {
  return mapskillPath(root, 'locks.json');
}

/** Reads .mapskill/locks.json. A missing file means no locks. A broken file is an error: the lock check then fails closed. */
export function readLocks(root: string): LocksResult {
  let text: string;
  try {
    text = fs.readFileSync(locksFile(root), 'utf8');
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === 'ENOENT') return { ok: true, locks: [] };
    return { ok: false, error: `cannot read locks.json: ${(err as Error).message}` };
  }
  let data: unknown;
  try {
    data = JSON.parse(text);
  } catch (err) {
    return { ok: false, error: `locks.json is not valid JSON: ${(err as Error).message}` };
  }
  const list = (data as { locks?: unknown } | null)?.locks;
  if (!Array.isArray(list)) return { ok: false, error: 'locks.json has no "locks" list' };
  const locks = list.filter(
    (l): l is Lock => typeof l === 'object' && l !== null && typeof (l as Lock).path === 'string' && (l as Lock).path !== '',
  );
  return { ok: true, locks };
}

const fold = (s: string): string => (process.platform === 'win32' ? s.toLowerCase() : s);

/** The lock that covers `rel` (project-relative, '/' separators), if any. */
export function findLock(locks: Lock[], rel: string): Lock | undefined {
  const target = fold(rel);
  return locks.find((l) => {
    const p = fold(l.path);
    return p.endsWith('/') ? target.startsWith(p) : target === p;
  });
}

/** The lock path for a user-given path: project-relative, folders with a trailing '/'. Null when outside the project. */
export function lockPathFor(root: string, given: string): string | null {
  const rel = toProjectRel(root, given);
  if (rel === null) return null;
  try {
    if (fs.statSync(path.join(root, rel)).isDirectory()) return `${rel}/`;
  } catch {
    // a file that does not exist yet can still be locked
  }
  return rel;
}

function current(root: string): Lock[] {
  const read = readLocks(root);
  if (!read.ok) throw new Error(read.error);
  return read.locks;
}

function save(root: string, locks: Lock[]): void {
  ensureMapskillDir(root);
  writeJsonAtomic(locksFile(root), { version: 1, locks });
}

/** Locks the given files or folders. Returns all locks afterwards. Throws for a path outside the project. */
export function addLocks(root: string, paths: string[], label?: string): Lock[] {
  const locks = current(root);
  for (const given of paths) {
    const p = lockPathFor(root, given);
    if (p === null) throw new Error(`Outside the project: ${given}`);
    if (locks.some((l) => fold(l.path) === fold(p))) continue;
    locks.push({ path: p, ...(label ? { label } : {}), lockedAt: Date.now() });
  }
  save(root, locks);
  return locks;
}

/** Removes the locks for the given files or folders. Returns the locks that remain. */
export function removeLocks(root: string, paths: string[]): Lock[] {
  const drop = new Set(paths.map((given) => lockPathFor(root, given)).filter((p): p is string => p !== null).map(fold));
  const locks = current(root).filter((l) => !drop.has(fold(l.path)));
  save(root, locks);
  return locks;
}
```

```ts
import path from 'node:path';
import { parseArgs } from 'node:util';
import { addLocks, readLocks, removeLocks } from './locks';
import { findProjectRoot } from './project-path';

type Write = (s: string) => void;
const stdout: Write = (s) => process.stdout.write(s);

function parse(argv: string[], cwd: string): { root: string; paths: string[]; label?: string } {
  const { values, positionals } = parseArgs({
    args: argv,
    allowPositionals: true,
    options: { label: { type: 'string' } },
  });
  return { root: findProjectRoot(cwd), paths: positionals.map((p) => path.resolve(cwd, p)), label: values.label };
}

/** `mapskill lock <path...> [--label text]`: Claude must ask the user before changing these files or folders. */
export function runLock(argv: string[], cwd = process.cwd(), write: Write = stdout): number {
  const { root, paths, label } = parse(argv, cwd);
  if (paths.length === 0) {
    write('Usage: mapskill lock <file or folder...> [--label text]\n');
    return 1;
  }
  try {
    const read = readLocks(root);
    const before = new Set(read.ok ? read.locks.map((l) => l.path) : []);
    for (const l of addLocks(root, paths, label)) if (!before.has(l.path)) write(`Locked ${l.path}\n`);
    return 0;
  } catch (err) {
    write(`${(err as Error).message}\n`);
    return 1;
  }
}

/** `mapskill unlock <path...>` */
export function runUnlock(argv: string[], cwd = process.cwd(), write: Write = stdout): number {
  const { root, paths } = parse(argv, cwd);
  if (paths.length === 0) {
    write('Usage: mapskill unlock <file or folder...>\n');
    return 1;
  }
  try {
    const left = removeLocks(root, paths);
    write(`${left.length} lock${left.length === 1 ? '' : 's'} left\n`);
    return 0;
  } catch (err) {
    write(`${(err as Error).message}\n`);
    return 1;
  }
}

/** `mapskill locks [dir]`: lists the locks of the project that contains `dir`. */
export function runLocks(argv: string[], cwd = process.cwd(), write: Write = stdout): number {
  const root = findProjectRoot(path.resolve(cwd, argv[0] ?? '.'));
  const read = readLocks(root);
  if (!read.ok) {
    write(`${read.error}\n`);
    return 1;
  }
  if (read.locks.length === 0) write('No locks\n');
  for (const l of read.locks) write(`${l.path}${l.label ? ` (${l.label})` : ''}\n`);
  return 0;
}
```

```ts
// packages/core/src/agent/similar.ts
import type { FileFacts, FunctionFact, MapNode } from '../model/types';
import { extractFacts } from '../parse/extract';

export interface SimilarQuery {
  name?: string;
  code?: string;
}

export interface SimilarMatch {
  name: string;
  file: string;
  startLine: number;
  endLine: number;
  nodeId?: string;
  /** 0..1, higher is more alike. */
  score: number;
  reason: 'same-code' | 'renamed-copy' | 'similar-code' | 'similar-name';
}

const MIN_SCORE = 0.3;
const TEST_FILE = /\.(test|spec)\.[cm]?[jt]sx?$/;

/** Lower-case words of an identifier: formatDateISO -> format, date, iso. */
export function nameWords(name: string): string[] {
  return name
    .replace(/([a-z0-9])([A-Z])/g, '$1 $2')
    .replace(/([A-Z]+)([A-Z][a-z])/g, '$1 $2')
    .split(/[^A-Za-z0-9]+/)
    .filter(Boolean)
    .map((w) => w.toLowerCase());
}

function jaccard<T>(a: Set<T>, b: Set<T>): number {
  if (a.size === 0 || b.size === 0) return 0;
  let inter = 0;
  for (const x of a) if (b.has(x)) inter++;
  return inter / (a.size + b.size - inter);
}

/** The first function in `code`; code that holds no function is treated as a function body. */
function snippetFunction(code: string): FunctionFact | undefined {
  for (const file of ['snippet.ts', 'snippet.tsx']) {
    const facts = extractFacts(file, code);
    if (!facts.parseError && facts.functions[0]) return facts.functions[0];
  }
  return extractFacts('snippet.tsx', `function snippet() {\n${code}\n}\n`).functions[0];
}

function nameScore(query: string, name: string): number {
  const q = query.toLowerCase();
  const n = name.toLowerCase();
  let score = jaccard(new Set(nameWords(query)), new Set(nameWords(name))) * 0.9;
  if (q.length >= 3 && n.length >= 3 && (n.includes(q) || q.includes(n))) score = Math.max(score, 0.55);
  return score;
}

/** Existing functions that look like `query` (by name, by code, or both), best first. */
export function findSimilar(
  files: Record<string, FileFacts>,
  nodes: MapNode[],
  query: SimilarQuery,
  limit = 5,
): SimilarMatch[] {
  const name = query.name?.trim() || undefined;
  const probe = query.code?.trim() ? snippetFunction(query.code) : undefined;
  if (!name && !probe) return [];
  const probeShingles = probe ? new Set(probe.shingles) : undefined;
  const out: SimilarMatch[] = [];
  for (const f of Object.values(files)) {
    if (TEST_FILE.test(f.path)) continue;
    for (const fn of f.functions) {
      let score = 0;
      let reason: SimilarMatch['reason'] = 'similar-name';
      if (probe && probeShingles) {
        if (fn.exactHash === probe.exactHash) [score, reason] = [1, 'same-code'];
        else if (fn.renamedHash === probe.renamedHash) [score, reason] = [0.95, 'renamed-copy'];
        else [score, reason] = [jaccard(probeShingles, new Set(fn.shingles)), 'similar-code'];
      }
      if (name) {
        const byName = nameScore(name, fn.name);
        if (byName > score) [score, reason] = [byName, 'similar-name'];
      }
      if (score < MIN_SCORE) continue;
      const nodeId = (nodes.find((n) => n.file === f.path && n.id.endsWith(`#${fn.name}`)) ?? nodes.find((n) => n.file === f.path))?.id;
      out.push({
        name: fn.name,
        file: f.path,
        startLine: fn.startLine,
        endLine: fn.endLine,
        ...(nodeId ? { nodeId } : {}),
        score: Math.round(score * 100) / 100,
        reason,
      });
    }
  }
  out.sort((a, b) => b.score - a.score || (a.file < b.file ? -1 : a.file > b.file ? 1 : 0) || a.startLine - b.startLine);
  return out.slice(0, limit);
}
```

```ts
import type { PublicGraph } from '../graph/delta';
import type { MapNode, Zone } from '../model/types';
import { ZONE_LABELS } from '../text/labels';

const ZONES: Zone[] = ['pages', 'server', 'blocks', 'shared', 'data', 'outside', 'tests'];
/** Code-unit order: the same on every machine, unlike localeCompare. */
const cmp = (a: string, b: string): number => (a < b ? -1 : a > b ? 1 : 0);

export function nodeLine(n: MapNode, health: Record<string, number>): string {
  const where = n.file ? ` ${n.file}${n.startLine ? `:${n.startLine}-${n.endLine ?? n.startLine}` : ''}` : '';
  const h = health[n.id];
  return `- ${n.label} [${n.type}]${where}${h !== undefined && h < 10 ? ` (health ${h}/10)` : ''}`;
}

/** A short text map of the project for Claude: zones, their parts and health. */
export function mapOverview(g: PublicGraph, options: { maxNodes?: number; maxChars?: number } = {}): string {
  const maxNodes = options.maxNodes ?? 80;
  const maxChars = options.maxChars ?? 8000;
  const certain = g.findings.filter((f) => f.certainty === 'certain').length;
  const health = (id: string): number => g.health[id] ?? 10;
  const groups = ZONES.map((zone) => ({
    zone,
    nodes: g.nodes
      .filter((n) => n.zone === zone && !n.planned)
      .sort(
        (a, b) =>
          health(a.id) - health(b.id) ||
          cmp(a.file ?? '', b.file ?? '') ||
          (a.startLine ?? 0) - (b.startLine ?? 0) ||
          cmp(a.id, b.id),
      ),
  })).filter((x) => x.nodes.length > 0);

  const quota = new Map<Zone, number>();
  let left = maxNodes;
  const base = Math.floor(maxNodes / Math.max(groups.length, 1));
  for (const x of groups) {
    const q = Math.min(x.nodes.length, base);
    quota.set(x.zone, q);
    left -= q;
  }
  for (const x of groups) {
    const extra = Math.min(left, x.nodes.length - quota.get(x.zone)!);
    quota.set(x.zone, quota.get(x.zone)! + extra);
    left -= extra;
  }

  const lines = [
    `Project ${path.basename(g.root)} (${g.framework}): ${g.fileCount} files, ${g.nodes.length} parts, ` +
      `${g.findings.length} findings (${certain} certain, ${g.findings.length - certain} likely).`,
    'Health is 1-10, where 10 means no findings.',
  ];
  const hidden: string[] = [];
  for (const x of groups) {
    const zoneHealth = Math.round(x.nodes.reduce((s, n) => s + health(n.id), 0) / x.nodes.length);
    lines.push('', `${ZONE_LABELS[x.zone].en} (${x.nodes.length} parts, health ${zoneHealth}/10)`);
    const shown = quota.get(x.zone)!;
    for (const n of x.nodes.slice(0, shown)) lines.push(nodeLine(n, g.health));
    if (x.nodes.length > shown) hidden.push(`${x.nodes.length - shown} in ${ZONE_LABELS[x.zone].en}`);
  }
  if (hidden.length > 0) lines.push('', `Not shown: ${hidden.join(', ')}. Use node_details or find_similar for more.`);
  if (g.unreadableFiles.length > 0) lines.push('', `Could not be read (last good version used): ${g.unreadableFiles.join(', ')}`);
  const text = lines.join('\n');
  if (text.length <= maxChars) return text;
  const marker = '\n(cut to fit)';
  return text.slice(0, Math.max(0, maxChars - marker.length)) + marker;
}
```

```ts
// packages/core/src/agent/details.ts
import type { PublicGraph } from '../graph/delta';
import type { MapNode } from '../model/types';
import { ZONE_LABELS } from '../text/labels';

const MAX_NODES = 10;

function label(g: PublicGraph, id: string): string {
  const n = g.nodes.find((x) => x.id === id);
  if (!n) return id;
  return `${n.label} [${n.type}]${n.file ? ` (${n.file})` : ''}`;
}

function describe(g: PublicGraph, n: MapNode): string {
  const lines = [`${n.label} [${n.type}] in ${ZONE_LABELS[n.zone].en}`];
  if (n.file) lines.push(`File: ${n.file}${n.startLine ? ` lines ${n.startLine}-${n.endLine ?? n.startLine}` : ''}`);
  if (n.route) lines.push(`Route: ${n.route}`);
  lines.push(`Health: ${g.health[n.id] ?? 10}/10`);
  const into = g.edges.filter((e) => e.to === n.id && (e.kind === 'uses' || e.kind === 'tests'));
  const out = g.edges.filter((e) => e.from === n.id);
  const list = (ids: string[]): string => (ids.length ? [...new Set(ids)].map((id) => label(g, id)).join('; ') : '(nothing)');
  lines.push(`Used by: ${list(into.map((e) => e.from))}`);
  lines.push(`Uses: ${list(out.filter((e) => e.kind === 'uses').map((e) => e.to))}`);
  const data = out.filter((e) => e.kind !== 'uses' && e.kind !== 'tests');
  if (data.length) lines.push(`Data and services: ${data.map((e) => `${label(g, e.to)} (${e.kind})`).join('; ')}`);
  const findings = g.findings.filter((f) => f.nodeIds.includes(n.id));
  if (findings.length === 0) lines.push('Findings: none');
  else {
    lines.push('Findings:');
    for (const f of findings) lines.push(`- [${f.certainty}] ${f.message.en}`, `  For Claude: ${f.instruction}`);
  }
  return lines.join('\n');
}

/** Details about one node (by id) or about every node in a file (by path). Null when nothing matches. */
export function nodeDetails(g: PublicGraph, query: { id?: string; path?: string }): string | null {
  let nodes: MapNode[] = [];
  if (query.id) nodes = g.nodes.filter((n) => n.id === query.id);
  else if (query.path) {
    const p = query.path.replace(/\\/g, '/').replace(/^\.\//, '');
    nodes = g.nodes.filter((n) => n.file === p);
  }
  if (nodes.length === 0) return null;
  const shown = nodes.slice(0, MAX_NODES).map((n) => describe(g, n));
  if (nodes.length > MAX_NODES) shown.push(`(${nodes.length - MAX_NODES} more parts in this file)`);
  return shown.join('\n\n');
}
```

| Metod och väg | Kropp eller parametrar | Svar |
|---|---|---|
| `POST /api/touched` | `{ files: string[], toolUseId?, sessionId?, bash?: boolean }` | `{ ok: true }` |
| `POST /api/stop` | `{ sessionId?: string }` (standard `default`) | `StopAnswer` |
| `GET /api/findings` | som i M2, plus `session=latest` | som i M2 |
| `GET /api/overview` | `maxNodes?` (heltal 1–500) | `{ text: string }` |
| `POST /api/similar` | `{ name?: string, code?: string }`, `code` högst 20 000 tecken | `{ matches: SimilarMatch[] }` |
| `GET /api/node` | `id` eller `path` | `{ text: string }`, eller 404 `{ error: 'no such node' }` |

Regler för `POST /api/stop`:
1. Töm kön (`flushNow`).
2. Ta sessionens aktuella varv. Saknas det: `{ unknownTurn: true, alreadyReported: false, total: 0, findings: [] }`.
3. Räkna nya fynd i varvet som är `certain` och rör filer Claude rört (`touchedOnly`).
4. Inga fynd ger `total: 0`. Varvet markeras då inte som rapporterat, så en senare stoppkontroll i samma varv kan fortfarande rapportera.
5. Annars: om `claimStop(turnId)` är falskt, svara `alreadyReported: true` och `findings: []`. Om det är sant, svara med de första 5 fynden och `total` = antal.

Regler för `bash: true`:
1. Se till att sessionen har ett varv (`touch` med tom fillista), innan något töms. Varvets baslinje tas då före Bash-ändringarna.
2. Töm kön, lägg det `findDrift` hittar i kön som `claude`, töm igen. Om `findDrift` kastar: logga och fortsätt.
3. Varje fil som ändrats sedan varvets förra rapport (`markReported`) räknas som rörd av Claude. Daemonen minns de senaste 5 000 ändrade sökvägarna med tid.

Vanliga `touched`-anrop (utan `bash`) anropar också `markReported`, så att nästa Bash-rapport bara tar det som hänt efter dem.

```ts
// Hooks must stay light: no runtime import of @mapskill/core anywhere under hooks/ (it loads the TypeScript compiler).

/** The fields Mapskill reads from Claude Code's hook input. All optional: hooks must survive any shape. */
export interface HookInput {
  session_id?: string;
  cwd?: string;
  hook_event_name?: string;
  source?: string;
  prompt?: string;
  tool_name?: string;
  tool_input?: Record<string, unknown>;
  tool_use_id?: string;
  stop_hook_active?: boolean;
}

/** Reads the hook's JSON from stdin. Garbage, too much input or a stalled pipe give `{}`. */
export async function readHookInput(
  stream: NodeJS.ReadableStream,
  options: { maxBytes?: number; timeoutMs?: number } = {},
): Promise<HookInput> {
  const maxBytes = options.maxBytes ?? 1_000_000;
  const read = (async () => {
    const chunks: Buffer[] = [];
    let size = 0;
    for await (const chunk of stream) {
      const buf = typeof chunk === 'string' ? Buffer.from(chunk) : (chunk as Buffer);
      size += buf.length;
      if (size > maxBytes) return '';
      chunks.push(buf);
    }
    return Buffer.concat(chunks).toString('utf8');
  })();
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<string>((resolve) => {
    timer = setTimeout(() => resolve(''), options.timeoutMs ?? 2000);
  });
  const text = await Promise.race([read, timeout]).catch(() => '');
  clearTimeout(timer);
  try {
    const value: unknown = JSON.parse(text);
    return value && typeof value === 'object' && !Array.isArray(value) ? (value as HookInput) : {};
  } catch {
    return {};
  }
}

/** The project root: CLAUDE_PROJECT_DIR, else the session's cwd, else this process's cwd. */
export function hookRoot(input: HookInput, env: NodeJS.ProcessEnv): string {
  const dir = env.CLAUDE_PROJECT_DIR || (typeof input.cwd === 'string' && input.cwd) || process.cwd();
  return canonicalRoot(dir);
}

/** True when Mapskill should map this folder: it has a package.json or a tsconfig.json. */
export function isJsProject(root: string): boolean {
  return fs.existsSync(path.join(root, 'package.json')) || fs.existsSync(path.join(root, 'tsconfig.json'));
}

    const v = ti[key];
    if (typeof v === 'string' && v.trim() !== '') return v;
  }
  return undefined;
```

```ts
import { editedFile } from './input';

/** Blocks edits to files the user locked. Works without the daemon: it reads .mapskill/locks.json directly. */
export const preToolUse: HookHandler = async ({ input, root }) => {
  const file = editedFile(input);
  if (!file) return ALLOW;
  const rel = toProjectRel(root, file);
  if (rel === null) return ALLOW;
  const read = readLocks(root);

    };

  const lock = findLock(read.locks, rel);
```

```ts
import { logHookProblem } from './log';
import { preToolUse } from './pre-tool-use';

export interface HookResult {
  exitCode: number;
  stdout?: string;
  stderr?: string;
}

export interface HookContext {
  input: HookInput;
  root: string;
  jsProject: boolean;
  env: NodeJS.ProcessEnv;
}

export type HookHandler = (ctx: HookContext) => Promise<HookResult>;

export const HOOK_EVENTS = ['session-start', 'user-prompt-submit', 'pre-tool-use', 'post-tool-use', 'stop'] as const;
export type HookEvent = (typeof HOOK_EVENTS)[number];

export const ALLOW: HookResult = { exitCode: 0 };

/** Inner deadlines, below the timeouts in plugin/hooks/hooks.json. */
const DEADLINE_MS: Record<HookEvent, number> = {
  'session-start': 9000,
  'user-prompt-submit': 4000,
  'pre-tool-use': 4000,
  'post-tool-use': 4000,
  stop: 12_000,
};

const isEvent = (e: string): e is HookEvent => (HOOK_EVENTS as readonly string[]).includes(e);

/** Handlers are filled in by Task 6; tests may pass their own. */
const builtIn: Partial<Record<HookEvent, HookHandler>> = {
  'pre-tool-use': preToolUse,
};

/**
 * Runs one hook. Never throws. Everything except a lock decision is fail-open: an error or a timeout lets Claude
 * continue and leaves a line in .mapskill/log.txt.
 */
export async function runHook(
  event: string,
  io: { stdin: NodeJS.ReadableStream; env: NodeJS.ProcessEnv },
  handlers: Partial<Record<HookEvent, HookHandler>> = builtIn,
): Promise<HookResult> {
  if (!isEvent(event)) return { exitCode: 1, stderr: `Unknown hook event: ${event}. Expected one of ${HOOK_EVENTS.join(', ')}.\n` };
  const handler = handlers[event];
  const input = await readHookInput(io.stdin);
  const root = hookRoot(input, io.env);
  if (!handler) return ALLOW;
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timedOut = Symbol('timeout');
  try {
    const result = await Promise.race([
      handler({ input, root, jsProject: isJsProject(root), env: io.env }),
      new Promise<typeof timedOut>((resolve) => {
        timer = setTimeout(() => resolve(timedOut), DEADLINE_MS[event]);
      }),
    ]);
    if (result === timedOut) {
      logHookProblem(root, event, 'timed out');
      return ALLOW;
    }
    return result;
  } catch (err) {
    logHookProblem(root, event, err);
    return ALLOW;
  } finally {
    clearTimeout(timer);
  }
}
```

```ts
// packages/cli/src/hooks/session-start.ts
import { ensureDaemon } from '../daemon/client';
import { readLocks, type Lock } from '../locks';
import { ALLOW, type HookHandler } from './run';

export function sessionContext(running: boolean, locks: Lock[] | null): string {
  const lines = [
    running
      ? 'Mapskill is mapping this project. Before you add a function, component or file, call the Mapskill find_similar tool and reuse what fits; call map_overview to see where things belong.'
      : 'Mapskill could not start its background process; its tools may answer slowly or not at all. Locks still apply.',
  ];
  if (locks === null) lines.push('Mapskill cannot read .mapskill/locks.json; ask the user before changing files they may have locked.');
  else if (locks.length > 0) {
    lines.push(`Locked by the user (do not change without asking): ${locks.map((l) => (l.label ? `${l.path} (${l.label})` : l.path)).join(', ')}`);
  }
  return lines.join('\n');
}

/** Starts the daemon and tells Claude that Mapskill is there and what is locked. */
export const sessionStart: HookHandler = async ({ root, jsProject }) => {
  if (!jsProject) return ALLOW;
  const info = await ensureDaemon(root, { timeoutMs: 3000 });
  const read = readLocks(root);
  const additionalContext = sessionContext(info !== null, read.ok ? read.locks : null);
  return { exitCode: 0, stdout: JSON.stringify({ hookSpecificOutput: { hookEventName: 'SessionStart', additionalContext } }) };
};
```

```ts
import type { StopAnswer } from '@mapskill/core';
import { liveDaemon, request } from '../daemon/client';
import { ALLOW, type HookHandler } from './run';

export function formatStopReason(answer: StopAnswer): string {
  const n = answer.total;
  const lines = [`Mapskill found ${n} new problem${n === 1 ? '' : 's'} in files you changed this turn:`];
  answer.findings.forEach((f, i) => lines.push(`${i + 1}. ${f.message.en}`, `   What to do: ${f.instruction}`));
  const hidden = n - answer.findings.length;
  if (hidden > 0) lines.push(`(${hidden} more not shown; the Mapskill turn_findings tool lists them.)`);
  lines.push('Fix the ones you agree with. For any you leave as they are, tell the user in one plain sentence why.');
  return lines.join('\n');
}

/** Before Claude ends its turn: block once with the new certain findings in the files Claude changed. */
export const stop: HookHandler = async ({ input, root, jsProject }) => {
  if (input.stop_hook_active === true || !jsProject) return ALLOW;
  const info = await liveDaemon(root);
  if (!info) return ALLOW;
  const answer = await request<StopAnswer>(info, 'POST', '/api/stop', { sessionId: input.session_id ?? 'default' }, 8000);
  if (answer.findings.length === 0) return ALLOW;
  return { exitCode: 0, stdout: JSON.stringify({ decision: 'block', reason: formatStopReason(answer) }) };
};
```

```ts
// packages/cli/src/mcp/server.ts
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import type { Finding, SimilarMatch } from '@mapskill/core';
import { z } from 'zod';
import { DaemonRequestError, ensureDaemon, request } from '../daemon/client';
import { DAEMON_VERSION, type DaemonInfo } from '../daemon/info';
import { isJsProject } from '../hooks/input';
import { canonicalRoot } from '../project-path';

type ToolResult = { content: { type: 'text'; text: string }[]; isError?: boolean };

const ok = (text: string): ToolResult => ({ content: [{ type: 'text', text }] });
const fail = (text: string): ToolResult => ({ content: [{ type: 'text', text }], isError: true });

const REASONS: Record<SimilarMatch['reason'], string> = {
  'same-code': 'same code',
  'renamed-copy': 'renamed copy',
  'similar-code': 'similar code',
  'similar-name': 'similar name',
};

export function formatMatches(matches: SimilarMatch[]): string {
  if (matches.length === 0) return 'No existing function looks like this. Writing a new one is fine.';
  const lines = matches.map(
    (m, i) =>
      `${i + 1}. ${m.name} in ${m.file}:${m.startLine}-${m.endLine} (${REASONS[m.reason]}, ${m.score})` +
      (m.nodeId ? ` [node ${m.nodeId}]` : ''),
  );
  lines.push('Reuse or extend one of these if it fits; import it instead of writing a copy.');
  return lines.join('\n');
}

export function formatFindings(findings: Finding[]): string {
  if (findings.length === 0) return 'No new findings in the current turn.';
  return findings.map((f) => `- [${f.certainty}] ${f.message.en}\n  What to do: ${f.instruction}`).join('\n');
}

export function createMcpServer(options: { root: string; daemon: () => Promise<DaemonInfo | null> }): McpServer {
  const server = new McpServer({ name: 'mapskill', version: DAEMON_VERSION });

  /** Runs a tool body against the daemon; turns every failure into a one-sentence tool error. */
  const withDaemon = async (body: (info: DaemonInfo) => Promise<ToolResult>): Promise<ToolResult> => {
    if (!isJsProject(options.root)) {
      return fail('Mapskill maps JavaScript and TypeScript projects; this folder has no package.json or tsconfig.json.');
    }
    try {
      const info = await options.daemon();
      if (!info) return fail('Mapskill is not running for this project.');
      return await body(info);
    } catch (err) {
      return fail(`Mapskill could not answer: ${err instanceof Error ? err.message : String(err)}`);
    }
  };

  server.registerTool(
    'map_overview',
    {
      description:
        'A short map of this project: its zones (pages, server, building blocks, shared helpers, data), the parts in each, and their health. Call it to see where new code belongs.',
      inputSchema: { maxNodes: z.number().int().min(10).max(300).optional() },
    },
    async ({ maxNodes }) =>
      withDaemon(async (info) => {
        const q = maxNodes ? `?maxNodes=${maxNodes}` : '';
        return ok((await request<{ text: string }>(info, 'GET', `/api/overview${q}`, undefined, 10_000)).text);
      }),
  );

  server.registerTool(
    'find_similar',
    {
      description:
        'Before writing a new function or component: give its planned name and/or code, and get up to 5 existing functions in this project that look the same, so you can reuse one instead of writing a copy.',
      inputSchema: { name: z.string().max(200).optional(), code: z.string().max(20_000).optional() },
    },
    async ({ name, code }) => {
      if (!name?.trim() && !code?.trim()) return fail('Give a name, code, or both.');
      return withDaemon(async (info) => {
        const { matches } = await request<{ matches: SimilarMatch[] }>(info, 'POST', '/api/similar', { name, code }, 10_000);
        return ok(formatMatches(matches));
      });
    },
  );

  server.registerTool(
    'node_details',
    {
      description:
        'Details about one part of the map (by node id from map_overview or find_similar) or about the parts in one file (by project-relative path): who uses it, what it uses, and its findings.',
      inputSchema: { nodeId: z.string().max(500).optional(), path: z.string().max(500).optional() },
    },
    async ({ nodeId, path }) => {
      if (!nodeId && !path) return fail('Give a nodeId or a path.');
      return withDaemon(async (info) => {
        const q = nodeId ? `id=${encodeURIComponent(nodeId)}` : `path=${encodeURIComponent(path!)}`;
        try {
          return ok((await request<{ text: string }>(info, 'GET', `/api/node?${q}`, undefined, 10_000)).text);
        } catch (err) {
          if (err instanceof DaemonRequestError && err.status === 404) return ok('No part of the map matches that. Use map_overview to find ids.');
          throw err;
        }
      });
    },
  );

  server.registerTool(
    'turn_findings',
    {
      description: 'Problems Mapskill found in the code changed during the current turn (new duplicates, unused code, rule breaks).',
      inputSchema: {},
    },
    async () =>
      withDaemon(async (info) => {
        const { findings } = await request<{ findings: Finding[] }>(info, 'GET', '/api/findings?session=latest', undefined, 10_000);
        return ok(formatFindings(findings));
      }),
  );

  return server;
}

/** `mapskill mcp`: serves the tools over stdio until Claude Code closes the pipe. */
export async function runMcp(env: NodeJS.ProcessEnv = process.env): Promise<number> {
  const root = canonicalRoot(env.CLAUDE_PROJECT_DIR || process.cwd());
  const server = createMcpServer({ root, daemon: () => ensureDaemon(root, { timeoutMs: 8000 }) });
  const transport = new StdioServerTransport();
  const closed = new Promise<void>((resolve) => {
    transport.onclose = () => resolve();
    process.stdin.once('end', () => resolve());
  });
  await server.connect(transport);
  await closed;
  return 0;
}
```

```ts
// packages/cli/src/build/bundle.ts
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { build, type Metafile } from 'esbuild';

export interface BundleReport {
  /** Absolute path of mapskill.mjs. */
  entry: string;
  /** Source files (paths as esbuild reports them, '/' separators) loaded when `mapskill hook` runs. */
  hookClosureInputs: string[];
}

const here = path.dirname(fileURLToPath(import.meta.url));
const repoRoot = path.resolve(here, '../../../..');

/** Output files reachable from `start` through static imports only. */
function staticClosure(meta: Metafile, start: string): Set<string> {
  const seen = new Set<string>();
  const queue = [start];
  while (queue.length > 0) {
    const out = queue.pop()!;
    if (seen.has(out)) continue;
    seen.add(out);
    for (const imp of meta.outputs[out]?.imports ?? []) if (imp.kind === 'import-statement' && !imp.external) queue.push(imp.path);
  }
  return seen;
}

/** Bundles the CLI into `outdir`: mapskill.mjs plus chunks/, loadable by plain node without node_modules. */
export async function bundlePlugin(outdirArg: string): Promise<BundleReport> {
  const outdir = path.resolve(outdirArg);
  fs.rmSync(outdir, { recursive: true, force: true });
  const result = await build({
    absWorkingDir: repoRoot,
    entryPoints: { mapskill: 'packages/cli/src/bin.ts' },
    outdir,
    outExtension: { '.js': '.mjs' },
    chunkNames: 'chunks/[name]-[hash]',
    bundle: true,
    splitting: true,
    format: 'esm',
    platform: 'node',
    target: 'node22',
    // ws tries these optional native helpers and works without them.
    external: ['bufferutil', 'utf-8-validate'],
    // Bundled CommonJS (typescript, ws) calls require() for Node built-ins; ESM output needs a real require.
    banner: { js: "import { createRequire as __mapskillCreateRequire } from 'node:module'; const require = __mapskillCreateRequire(import.meta.url);" },
    metafile: true,
    logLevel: 'warning',
  });
  const meta = result.metafile;
  const rel = (p: string): string => path.relative(repoRoot, p).split(path.sep).join('/');
  const entryOut = Object.keys(meta.outputs).find((o) => meta.outputs[o].entryPoint === 'packages/cli/src/bin.ts');
  if (!entryOut) throw new Error('bundle has no entry output');
  // The hook command's chunk: the output that holds hooks/run.ts.
  const hookOut = Object.keys(meta.outputs).find((o) => 'packages/cli/src/hooks/run.ts' in meta.outputs[o].inputs);
  if (!hookOut) throw new Error('bundle has no chunk for the hooks');
  const outputs = new Set([...staticClosure(meta, entryOut), ...staticClosure(meta, hookOut)]);
  const hookClosureInputs = [...outputs].flatMap((o) => Object.keys(meta.outputs[o].inputs)).sort();
  return { entry: path.resolve(repoRoot, entryOut), hookClosureInputs: hookClosureInputs.map((p) => rel(path.resolve(repoRoot, p))) };
}

// `tsx packages/cli/src/build/bundle.ts <outdir>`
if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const outdir = process.argv[2] ?? 'plugin/dist';
  bundlePlugin(outdir).then(
    (r) => process.stdout.write(`Bundled ${r.entry}\n`),
    (err: unknown) => {
      process.stderr.write(`${err instanceof Error ? err.message : String(err)}\n`);
      process.exit(1);
    },
  );
}
```

Om `hookClosureInputs` innehåller `packages/core/src/`, leta upp den statiska importen med `meta.outputs[...].imports` och gör den dynamisk eller typ-bara. Ändra inte testet.

```markdown
- Before you create a new function, component or file, call `find_similar` (tool `mcp__plugin_mapskill_mapskill__find_similar`) with the name you plan and, if you have it, the code. If something fits, import and reuse it instead of writing a copy.
- Call `map_overview` to see the project's zones and where similar code already lives. Put new code where the project's structure says, not inside the file that happens to call it.
- Files the user locked in Mapskill must not be changed unless the user explicitly asks you to in this conversation. If an edit is refused because of a lock, tell the user which part is locked and ask.
- When the Stop hook lists Mapskill findings, fix the ones you agree with. For each one you leave, tell the user in one plain sentence why.
- When the user asks what a part of the map does, use `node_details` and answer in plain words. Answer in Swedish if the user writes Swedish. Avoid jargon, or explain it in a few words the first time.
```

- [ ] **Step 1: Skriv slutprovet**

```ts
// packages/cli/src/build/e2e.test.ts
import { spawnSync } from 'node:child_process';
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { fixture } from '@mapskill/core/test-helpers';
import { afterAll, beforeAll, describe, expect, it } from 'vitest';
import { runStop } from '../commands';
import { readDaemonInfo } from '../daemon/info';
import { addLocks } from '../locks';
import { canonicalRoot } from '../project-path';
import { bundlePlugin, type BundleReport } from './bundle';

let report: BundleReport;
let root: string;

beforeAll(async () => {
  report = await bundlePlugin(fs.mkdtempSync(path.join(os.tmpdir(), 'mapskill-e2e-bundle-')));
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'mapskill-e2e-'));
  fs.cpSync(fixture('messy-app'), dir, { recursive: true, filter: (src) => !src.split(path.sep).includes('.mapskill') });
  root = canonicalRoot(dir);
}, 120_000);

afterAll(async () => {
  if (root) await runStop(root, () => {});
});

function hook(event: string, input: Record<string, unknown>) {
  const started = Date.now();
  const r = spawnSync(process.execPath, [report.entry, 'hook', event], {
    input: JSON.stringify({ session_id: 'e2e', cwd: root, hook_event_name: event, ...input }),
    encoding: 'utf8',
    env: { ...process.env, CLAUDE_PROJECT_DIR: root },
    timeout: 30_000,
  });
  return { status: r.status, stdout: r.stdout, stderr: r.stderr, ms: Date.now() - started };
}

const duplicate = [
  'export function formatOrderDate(value: string): string {',
  '  const when = new Date(value);',
  '  const y = when.getFullYear();',
  "  const m = String(when.getMonth() + 1).padStart(2, '0');",
  "  const d = String(when.getDate()).padStart(2, '0');",
  '  return `${y}-${m}-${d}`;',
  '}',
  '',
].join('\n');

describe('a Claude turn through the bundled plugin', () => {
  it('starts the daemon, tracks the edit, blocks the stop once, and enforces a lock', () => {
    const start = hook('session-start', { source: 'startup' });
    expect(start.status).toBe(0);
    expect(JSON.parse(start.stdout).hookSpecificOutput.additionalContext).toContain('Mapskill is mapping this project');
    const info = readDaemonInfo(root);
    expect(info).not.toBeNull();
    expect(info!.pid).not.toBe(process.pid);

    expect(hook('user-prompt-submit', { prompt: 'Show order dates as YYYY-MM-DD' }).status).toBe(0);

    const file = path.join(root, 'lib', 'order-date.ts');
    fs.writeFileSync(file, duplicate);
    expect(hook('post-tool-use', { tool_name: 'Write', tool_use_id: 'w1', tool_input: { file_path: file, content: duplicate } }).status).toBe(0);

    const stop = hook('stop', { stop_hook_active: false });
    expect(stop.status).toBe(0);
    const decision = JSON.parse(stop.stdout) as { decision: string; reason: string };
    expect(decision.decision).toBe('block');
    expect(decision.reason).toContain('lib/order-date.ts');
    expect(decision.reason).toMatch(/formatDate/);

    expect(hook('stop', { stop_hook_active: true }).stdout).toBe('');
    expect(hook('stop', { stop_hook_active: false }).stdout).toBe('');

    addLocks(root, [path.join(root, 'lib', 'date.ts')], 'Datum');
    const blocked = hook('pre-tool-use', { tool_name: 'Edit', tool_input: { file_path: path.join(root, 'lib', 'date.ts') } });
    expect(blocked.status).toBe(2);
    expect(blocked.stderr).toContain('"Datum"');
    const allowed = hook('pre-tool-use', { tool_name: 'Edit', tool_input: { file_path: path.join(root, 'lib', 'cart.ts') } });
    expect(allowed.status).toBe(0);
    // The lock check loads no TypeScript compiler; it should be about as fast as starting node.
    expect(allowed.ms).toBeLessThan(2000);
  }, 120_000);
});
```

Tidsgränsen 2 sekunder för låskontrollen är generös (en hook utan kompilatorn tar typiskt 100–300 ms). Den fångar att någon av misstag har gjort en statisk import av core under `hooks/`.
